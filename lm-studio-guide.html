用 LM Studio 在自己的電腦跑 AI

這條路適合已在電腦上使用 LM Studio 的玩家。AI 模型會在你的電腦運行；不需要雲端連線金鑰（API Key），也不會自動改用付費雲端 AI。

請在同一台電腦操作。手機上的 localhost 只代表手機自己，不會自動連上家中電腦。為了安全，BAO/LAB 的本地連線只接受本機網址，不支援區域網路或遠端網址。

一、在 LM Studio 啟動本地 AI

  1. 到 LM Studio 官方網站 安裝 LM Studio。
  2. 下載並載入與你電腦硬體相容的 AI 模型。
  3. 進入 Developer／開發者 → Local Server／本地伺服器，按 Start Server。
  4. 在伺服器設定開啟 Enable CORS，讓 BAO/LAB 網頁可以向本機 AI 發出請求。

CORS 是瀏覽器的跨網站連線保護。只在信任的網站需要連接你電腦上的 LM Studio 時開啟；不要為了連線而開啟區域網路服務或把連接埠公開到網際網路。

LM Studio 常見的本機連線網址（Base URL）是 http://localhost:1234/v1；聊天端點通常為 http://localhost:1234/v1/chat/completions。

二、在 BAO/LAB 連接本地 AI

  1. 進入角色後，按「建立故事」→「連接 AI」。
  2. 在 AI 服務商（Provider）選擇 LM Studio（本地 AI）。
  3. 保留預設連線網址，按「讀取本機模型」，再從清單選擇 AI 模型（Model）。
  4. 需要時，依 LM Studio 顯示的名稱手動填寫模型代號（Model ID）。
  5. 完成角色與記憶設定後按「開始故事」。既有故事可按「AI 連線／切換模型」改用本地 AI，故事不會重置。

LM Studio 預設不需要連線金鑰（API Key）。只有你自行開啟 LM Studio 驗證時，才需填寫本機金鑰（API Token）。

三、卡住時怎麼檢查？

讀不到模型／Failed to fetch／CORS：確認 LM Studio 已啟動 Local Server、已開啟 Enable CORS，並用同一台電腦的瀏覽器開啟 BAO/LAB。

讀到模型但生成失敗：確認模型已載入，模型代號（Model ID）與 LM Studio 顯示完全相同；也檢查顯示記憶體和送給 AI 的故事脈絡（Context）是否超過電腦可用資源。

401 或 403：檢查是否自己開啟了 LM Studio 的本機金鑰；預設無驗證時不需填寫。

換裝置後：本地模式會記住模型與本機網址；若你使用本機金鑰，它不會存進故事存檔，需要重新輸入。

四、隱私與成本

本地模式會把角色卡、故事脈絡和聊天請求送到你電腦上的 LM Studio localhost，不會自動轉送到雲端 AI。模型與 LM Studio 是否自行記錄日誌、是否使用外部服務，取決於你安裝的軟體與模型設定。

本地推論不會產生雲端 API 逐次使用費，但仍會消耗電力、顯示記憶體與硬體資源。若另外設定雲端的記憶或狀態整理模型，該輔助請求仍會送往你指定的 AI 服務商。
