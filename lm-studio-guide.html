用 LM Studio 玩 BAO/LAB：本地 AI 連線教學

適合已在電腦上使用 LM Studio 的玩家。模型會在你的電腦上運行；不必將模型上傳給 BAO/LAB，也不需要雲端 API Key。

開始前

請在運行 LM Studio 的同一台電腦，使用瀏覽器開啟 BAO/LAB。手機開啟公開網站時，手機上的 localhost 指向手機本身，不會自動連到家中電腦。伺服器只需要監聽本機；不要為了連線而將它公開到網際網路。

一、在 LM Studio 啟動本機模型

  1. 開啟 LM Studio 官方網站，在電腦安裝 LM Studio。
  2. 下載與硬體相容的模型，或使用你已有的模型。玩家提到的「Gemma 4 26B 無限制版」只是模型名稱或第三方版本描述；BAO/LAB 不需要指定它，直接讀取 LM Studio 顯示的實際 Model ID 即可。
  3. 在 LM Studio 載入模型，進入 Developer／開發者 → Local Server／本地伺服器，按 Start Server。
  4. 在伺服器設定中啟用 Enable CORS，以允許 BAO/LAB 網頁向本機 API 發出跨來源請求。僅在信任的網頁使用本地伺服器時開啟；請保留僅本機存取，避免開啟「Serve on Local Network」或對外轉發連接埠。

LM Studio 預設 OpenAI 相容 API 位置：http://localhost:1234/v1。BAO/LAB 使用的聊天端點是 http://localhost:1234/v1/chat/completions。

二、在 BAO/LAB 選擇本地 AI

  1. 進入角色的「建立故事」→「模型連線」，在「API 服務／路由」選擇 LM Studio（本地 AI）。
  2. 保留預設連線網址，點「讀取本機模型」。從下拉選單選擇模型；也可以依照 LM Studio 顯示的實際 ID 手動填入 Model ID。
  3. LM Studio 預設不需要 API Key。只有你自行啟用 LM Studio 驗證時，才需要填寫本機 API Token。
  4. 完成其他角色與記憶設定，按「開始故事」。進入既有故事後，點「連接本地 AI」，可切換至 LM Studio、讀取模型並測試連線，故事不會因切換而重置。

無法開始時，請先用「讀取本機模型」確認伺服器有回應，再使用「測試本地模型」確認模型能產生文字。測試會在本機實際執行模型，可能增加電腦負載，不會收取雲端 API 逐次呼叫費用。

三、常見問題

讀取模型失敗／Failed to fetch／CORS：確認 LM Studio 已啟動 Server、已開啟 Enable CORS；允許瀏覽器詢問的本地網路存取權限。部分瀏覽器的 HTTPS 網站連到 HTTP localhost 仍可能受瀏覽器安全政策限制。試著更新瀏覽器並在同一台電腦開啟。

能讀到模型，但生成失敗：確認已載入模型、Model ID 與 LM Studio 顯示完全相同；檢查顯示記憶體與上下文是否超過可用資源。部分第三方模型或量化版本可能不支援長上下文或特定指令格式。

401 或 403：檢查 LM Studio 是否自行啟用了 API Token；預設無驗證時不需填寫任何 Key。

手機／另一台電腦無法連線：這個功能刻意只接受 localhost 或 127.0.0.1，並不接受區域網路或遠端 URL；請在 LM Studio 所在電腦使用 BAO/LAB。

故事重新開啟後：本地模式會保留模型與本機網址。若你啟用了本地 API Token，它不會寫入故事存檔，需重新輸入。

四、隱私與費用

選擇本地模式時，BAO/LAB 將角色卡、上下文及聊天請求發往你電腦的 LM Studio localhost API；不會自動轉送到雲端模型。模型是否自行使用外部服務、日誌如何保存，取決於你安裝的軟體與模型，請檢查其設定。若你另外啟用雲端記憶／狀態模型，那些輔助請求仍可能送往你自行指定的供應商。本地推論沒有雲端 API 逐次使用費，但仍有電力與硬體成本。
