# 夜灣 YoruBay｜Phone & Voice UX 審查與收斂
日期：2026-11-28（台灣時間）｜範圍：最新 main 的靜態程式碼與公開產品文件。此 PR 只建立決策與驗收規格，不改 runtime、不新增依賴、不移植外部程式碼。後續實作以本文件為 UX 方向，與 voice-system-roadmap.md、stage-capability-contract.md、player-ui-v2.md、AGENTS.md 的安全與相容契約共同使用；若有衝突，先明確修訂契約，不靜默放寬。

## 1. 產品定位與參考邊界
小手機是故事世界的線上社交介面，而不是另一個互不相干的遊戲或語音模型工作台。一般玩家不用理解 API 協議；進階玩家自行設定與付費。保留 local-first、BYOK、作者選配 phone_ui、Stage 選擇、故事回合與分支，零新增平台語音推論費用為目標。不自行訓練模型、不新增供應商、不下載權重、不增加常駐後端。
公開文件參考（2026-11-28 查閱，未安裝運行、未完整審查外部源碼或授權）：
- [ST-iPhonie](https://github.com/hey8v0/ST-iPhonie/blob/main/README.md)：服務設定與角色音色分離、點播、重播已生成音訊、未接來電與語音留言、正文與手機連動。其電話目前為角色語音＋玩家打字；不是雙向音訊通話。只參考產品行為。
- [Float Android](https://github.com/POPCORNqy/float-android/blob/main/README.md)：本機分庫、媒體引用、按需載入、按需麥克風權限、BYOK。其 AGPL-3.0-only 與 Android 原生服務不能直接移入夜灣；不改前端框架或引入原生 APK 架構。
- [ST-StoryPhone](https://github.com/fruit00001144-sys/000-ST-StoryPhone/blob/master/README.md)：主線與手機共享時間、事件、可見性；尤其 player-visible 不等於角色已知。僅參考通用概念，夜灣已有自己的 phone patch。
- [柚月小手機](https://github.com/gaigai315/yuzuki-phone/blob/main/README.md)：公開功能說明中的線上／線下、手勢返回、時間同步。作者明確限制商用及衍生發布；不研究或搬用受限實作、視覺或素材。
只用公開功能與通用互動模式制定夜灣獨立實作，不新增第三方 code、資產、依賴、品牌仿製。不把公開倉庫等同於已取得商用授權。

## 3. 實作順序（每階段小 PR，先對齊最新 main，禁止跨階段堆功能）
### U1 — 日常輸入收斂（先做）
- 手機 <=820px：移除 + 常用選單的獨立 STT，原生鍵盤處理普通語音轉文字；進階工具仍可存取既有 STT。語音訊息與鍵盤聽寫不是同一功能。
- 桌面：僅在支援且玩家選用時顯示簡潔麥克風，開始／停止、狀態、取消；明確同意後直接把完成的辨識合併至既有草稿，不自動送出普通文字、不跳至第二個 textarea。未支援或拒絕授權則仍可打字。
- 不覆蓋變動中的文字，不改圖片或音訊待送對象；保留原草稿、語言及長度限制、章節 guard、資源清理。第一次揭露可能連網；授權限當前頁面/明確會話與來源，拒絕／變更／失效要重新授權。
- 驗收：320/390/834/1440px、原有 composer 寬度及 +/圖片操作、鍵盤/觸控、draft merge、取消、拒絕、錯誤、切章、背景化、無額外 RP 模型請求；原 STT 接口仍可用。以既有回歸測試更新期待，不放寬版面門檻。

### U2 — Phone 語音訊息像聊天軟體
- 在聊天室 composer 提供清楚的錄音入口、按住錄製／放開（已授權時）送出、取消手勢；提供點按開始/停止、可預覽及手動送出作無障礙／偏好替代。權限尚未授予、錄音未開始或未驗證成功、pointercancel、收件/章節變更均不可送出。
- 區分本機保存、文字轉錄送出、原生音訊送模型；玩家知道選用哪條路，無能力時不要把本機音檔偽裝為 NPC 已收聽或默默改用付費服務。需明確選用模型理解；上傳格式不相容時提示並保留可行的安全路徑，不能假設錄音格式都相容。
- 只重用現有錄音／資產／native-turn transport；預設不新增網路請求；一次主線回合；保留原收件者、版本、群組可見性、容量、備份、刪除。無自動重送。
- NPC 普通文字：低干擾單一播放/停止控制；kind:voice：語音氣泡與可展開文字，不冒稱固定音檔、時長。這一步不擴展 provider。

### U3 — 一對一通話收斂
- 通話入口、角色頭像與姓名、可理解的狀態（就緒、聆聽、辨識、等待、說話、錯誤）、明確掛斷、按住說話；設定與逐字稿折疊。初次提示資料流、費用、上限，讓玩家選擇「放開送出」或「確認逐字稿」；沒有授權不能自動發送。記錄非秘密偏好而非自動恢復金鑰或付費授權。
- 放開送出只在有效 PTT 完成且有最終逐字稿時觸發，單次 latch；不能因 onend、pointerup/lostcapture 重複或在錯誤、取消、權限拒絕、超時、背景化、章節/成員變更後觸發。沿用 App.sendMessage、原收件範圍與 reply version guard；失敗保留可安全恢復文字，無自動重試。
- 通話回覆沿用既有授權聲線自動播放；按住說話先停止舊語音，掛斷停止麥克風與播放；已提交請求可能完成/收費。回覆不可讀旁白或其他聊天室。仍是輪流式 PTT，不宣稱原生即時音訊、全雙工或背景來電。
- 不要求新模型、WebRTC server、VAD、群組通話或自行訓練。瀏覽器無 STT 時提供文字降級。保留字幕開關與手動送出。

### U4 — 共用語音設定與重播
- 故事、Phone、通話共用現有 provider、角色 ID 與聲線設定；一般模式預設可用裝置聲線，進階端點與獨立 API key 收進設定，不與 RP key 混用。授權依原有期限、用量、章節、來源及資料範圍；不靜默延長、保存秘密或跳過同意。變更／到期才重新授權，付費服務的後續請求計量透明。
- 評估重播已生成的 BYOK 音訊：只有原文、角色、版本、聲線、語速及來源完全相符且玩家允許本機保存才可重用。沿用資產庫與清理、容量；禁止跨角色/會話串音。裝置朗讀不可假裝產生可保存音檔。先量測需求與成本，不新增永久聲線管理。
- 不綁定新供應商或雲同步；未驗收的服務不宣稱支援。

### U5 — 小手機 UX 整體驗收與後續決策
- 桌面與真手機：手機桌面/返回/通知、私訊與群聊、X、相簿、Story/Phone 切換、焦點與捲動位置、資料更新和鎖定。保留既有品牌、作者設定、主 Stage 選配與安全 renderer。
- 目前聊天室會完整遍歷已保留 rows 並置底；先用長對話 fixture 量測 DOM、捲動與回到訊息位置，再決定局部更新、分頁或虛擬列表，不能憑外部專案做法直接換框架。
- NPC 主動性沿用同輪故事 patch，不額外背景打模型；任何未接來電／留言／社群可見性增強需在 U1–U4 穩定後獨立設計。只有角色有理由才發生，時間/知情/回溯一致，不強迫每回合出現。
- 不導入錢包、商城、遊戲、22 個 App 等無關範圍。角色知識隔離加強需要獨立檢查 prompt 與記憶；本輪不改記憶架構。

## 4. 共同驗收紅線

零使用時不額外請求/權限/模型/下載；既有作品、純文字、圖片、狀態欄、記憶、分支、存檔及 Phone 收件/鎖定不退化。掛斷/取消/分頁切換清理資源；不假裝 provider 能力。每階段可回退 UI 且保留既有儲存格式。PR CI、合併、部署、正式站 smoke、真實裝置分開報告。文件 PR 未執行 runtime 測試，未部署。
