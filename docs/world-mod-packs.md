# BAO/LAB 世界 MOD v1（資料型）

這是世界模組的可分享設定檔，**不是**任意 JavaScript 外掛，也不是角色卡或故事備份。只有玩家主動匯入後，才安裝到目前故事的世界模組中。

## 作者／玩家使用

1. 開始或讀取故事，開啟「世界模組管理」。
2. 點「＋ 自訂模組」，設定名稱、欄位物件／清單、AI 追蹤頻率、Context、觸發詞。
3. 在「自訂欄位」新增英文欄位 ID、顯示名稱、文字／數字／數值條／是非類型；數字可設上下限。**物件**模組可設初始值，留空代表未設定。清單模組的欄位是每個清單項目的資料結構，不在此設定初始項目。
4. 按「套用到目前故事」，再按「匯出自訂 MOD」。匯出包含目前故事的所有玩家自訂模組定義與作者設定的初始值，不匯出故事進度、聊天紀錄、既有模組數值或 API Key。
5. 收到他人的 `.bao-mod.json` 檔後，在故事的「世界模組管理」選擇「匯入 MOD JSON」，閱讀內容摘要並確認；如果 ID 已存在、超出自訂模組上限或格式有誤，就拒絕匯入且不替換現有資料。

首次匯入會為新模組建立空物件／清單，再把作者設定的初始值填入物件欄位；不覆蓋已存在的欄位。啟用或停用模組仍使用原本的世界模組管理。每份故事最多 12 個玩家自訂模組，每個模組最多 24 個欄位。

## JSON 範例

```json
{
  "schema": "bao-lab-world-mod-pack",
  "version": 1,
  "meta": { "name": "關係擴充", "author": "示範作者", "release": "1.0.0" },
  "modules": [{
    "id": "custom_relationship",
    "label": "關係", "icon": "♡", "description": "只依明確事件追蹤關係變化。",
    "kind": "object", "tracking": "medium", "context": "relevant",
    "triggers": ["好感", "信任"],
    "fields": [{ "key": "affinity", "label": "好感", "type": "meter", "min": 0, "max": 100 }],
    "initial": { "affinity": 0 }
  }]
}
```

## 安全、費用與限制

- 匯入只解析 JSON，拒絕不支援版本、重複或衝突的模組 ID、非法欄位、無效數值與超過 128 KB 的檔案，不執行作者提供的程式碼。
- 模組名稱、說明、觸發詞與目前狀態可能隨玩家的主／狀態 AI 請求送往玩家自行選擇的服務商。匯入前請閱讀檔案來源與內容；請勿在 MOD 中放私人資訊或 API Key。
- `context: "ui_only"` 只代表不提供給主敘事模型；若追蹤頻率不是 `manual`，**仍可能**產生狀態模型請求。想完全避免該模組的 AI 更新請設 `tracking: "manual"`。
- 這一版不包括 MOD 商店、遠端自動更新、作者帳號、任意 JS／CSS 外掛或跨故事全域安裝。匯出範圍限玩家自訂模組，不包含角色卡原始內建模組。
- 停用／刪除模組不會自動清除故事中先前的模組數值；可保留舊故事進度。更改欄位 ID 時請留意原有數值不會自動改名。
