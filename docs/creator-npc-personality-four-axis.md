# Creator｜NPC 人格四軸輔助工具

## 目的
提供創作者一個**選填、純本機、無模型呼叫**的角色結構整理工具，不另設永久 NPC 系統、人格得分或每輪平台規則。四個欄位是人物背景「成因」、生活中的「外顯行為」、會使平常狀態被打破的「失控條件」，以及人物因此須承受的「代價」。不由程式或模型推定這些內容；作者須自行填寫。

## 操作
1. 前往 `character-studio.html` →「人物與世界」→「NPC 人格四軸」。
2. 填寫角色姓名、可選別名，以及四軸。可按「預覽整理結果」，此時**不會寫入角色卡，也不會將預覽中的文字存進草稿**。
3. 選擇位置：
   - **NPC 按需世界書（預設）**：將 `【世界書：人格四軸·姓名｜姓名,別名】` 加入原有的 `content.lore`，只有當名字／別名等關鍵字命中時才經既有召回模組讀取。這是多 NPC 群像的推薦選項，沒有每輪固定增加 system prefix。
   - **主要 AI 角色設定**：將 `【人物四軸：姓名】` 寫入 `content.profile`，適合單角色卡；根據角色卡原本的 Prompt 設定，這個欄位可能每輪提供給模型。
4. 點「加入角色卡（不自動儲存）」才修改原始 textarea。後續仍要按既有「儲存草稿」或「匯出」，不自動安裝、不公開作品。
5. 同名人物再次插入會偵測由工具建立的**同名專用區塊**：內容相同則不寫入，內容不同先詢問是否覆蓋，**不會覆蓋作者既有一般世界書條目或角色資料**。
6. 建立或載入另一張角色卡時，四軸編輯器的暫存欄位清空，避免將上一個人物草稿誤加到另一張卡。

## 與夜灣主站及 Creator MCP 相容
- 工具只使用既有 `content.profile` 和 `content.lore`，不添加角色 schema 必填欄位。原有 1.5 JSON 匯出、匯入與 Creator MCP 皆可依原欄位保存內容；作者是否將它用於特定作品由自己決定。
- 不改 `CharacterEngine` 對 NPC 的資訊隔離、行動權限或長期記憶，也不自動建立初始 NPC；人物仍須按作品需要自行加入角色名冊／初始狀態。
- 這只是人物設定整理，不代表任何人設必須有創傷、失控或懲罰情節。「失控條件」只描述作者設定的特殊狀態，「代價」是具體情節後果，無固定事件密度。
- 動態世界書依現有關鍵字／在場線索召回，不保證人物永遠不會被其他 NPC 聽見，也不是秘密硬隔離；敏感私密資料仍應使用現有角色知情權限。
- 沒有新增 API 呼叫、背景作業、雲端草稿或計費。按需世界書命中時仍計入模型輸入 Token，主角色設定按照既有設定計入。
