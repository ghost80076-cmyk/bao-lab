# 三界原創 NPC 性格範本

將來源 0–23、25–31 的性格、日常和人际功能抽象改寫成 31 位虛構成年人物，使用一般角色包。這不是原始人物的逐字搬遷；人物姓名、年齡和生活細節是新設計，來源只提供可用的非露骨性格方向。24 留待單獨審閱。

入口沿用「本故事的人物設定」的可攜角色選單。選擇範本先填入編輯表單，玩家可改名、指定本場身份和關係；按套用才加入目前故事。既有鏡月、顧沉和成人內容開關保留。範本不自動加入 NPC、不給好感或效忠、不宣稱背景事件已發生。

每位人物都有自己的日常、弱點與說話方式，並明確保留資訊限制和人際自主性。原始內容不在包中發布。provenance 記錄來源和改寫人物的 SHA-256；coverage 分開統計原生人物與世界事實。世界書仍是 115 個來源、752 章、45 個正式包。

驗證：可攜角色核心測試檢查實例隔離、一般內容門檻與 provenance；瀏覽器測試驗證範本選擇不改故事、明確套用後存檔及還原，並保留原作人物。使用既有故事角色提示流程，不新增 API 呼叫。
