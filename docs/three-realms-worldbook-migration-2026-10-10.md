## 分工

- 世界書提供靜態資料：地理、勢力、規矩、世界中的歷史與人物背景。
- 家主、族長、城主名字只是背景設定；不寫入 NPC 名冊，也不宣告角色已在玩家面前。
- 勢力的人數、境界、資源描述是原作設定，不是玩家當前狀態；實際故事進度仍由現有狀態系統保存。
- 原作的宗門收徒條件、城市刑罰、血脈與族群特色保持原文；不額外加入或改寫規則。
- 成人原型、真人演員模板、全局敘事指令、防蒸餾、HTML/XML 輸出規約與劇情秘密未混入此批世界資料。
- 修煉、業力、飛升、事件系統仍需要對接原生玩法與狀態，不能把這批資料說成已完成完整世界引擎。

## 召回與相容

六份新包皆使用 `world: three-realms`，能在同一故事共同選用，預設不啟用。沒有任何新增 `foundation` 常駐條目；沒有命中時不加資料。具名宗門／家族／城市與仙域按名稱召回，不沿用「角色」「任務」「下界宗門」等廣泛觸發詞。

「天道宗」只召回該宗的原文章節，不把同條來源中的其他四宗全部塞入。「玄天劍宗」不誤召回上界的玄天神殿。每輪 4 條／2,200 字限制由既有召回引擎統一計算，不因掛載六包而乘六。

既有下界地理試用包保持原 ID 與原內容，新包採獨立 ID；舊故事的釘選快照繼續使用原版。需要完整原文的故事可改選新包。此批不更改 Stable Prefix、API 中轉或全站規則。

## 原文追溯

`data/three-realms-worldbook-source-map.json` 保存來源世界書 ID、公開狀態、18 條來源索引、原文 SHA-256、字元數、每個目的條目的來源跨度與內文 SHA-256。分章只移除章節前後空白，不改寫字句；跨度連續覆蓋整個來源條目，不按相同標題覆寫。

`scripts/migrate-three-realms-worldbook.py` 以作者原始 JSON 為輸入重建資料包與索引：

```sh
python3 scripts/migrate-three-realms-worldbook.py /path/to/public-three-realms.json
node tests/three-realms-worldbook-core.cjs
```

工具只接受指定公開來源版本的 ID、191 條數量與地點分類，並僅處理固定審核清單；來源版本改變需要重新核對內容。原始 ZIP 不提交至公開儲存庫，索引不包含其餘未移植條目的內文與標題。
