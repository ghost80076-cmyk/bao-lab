# 三界九域：原生事件引導

來源是作者公開匯出版 `b43bd078-1b19-46e8-bfc8-952660be367d` 的零起算 173–183，共 11 條事件設計指令。這些指令經結構化轉換為原生敘事手法，不列入前批 624 章世界資料的章節總數。

## 操作

進入故事 → 世界模組管理 → 勾選「三界事件引導」並套用 → 快捷指令的「三界事件」組 → 選擇事件 → 確認輸入內容後送出。事件模組頁籤也可開啟指令。可用機運、危機、情感、突破、陰謀、探索、社交、資源、時間、因果、神秘 11 種。

預設未啟用。玩家設定保存於故事原有 `worldModuleCustomization`，可停用、恢復、備份及以故事擴充設定包攜出；其他故事不受影響。作者可以用原有 `world_modules` 明確選用 `three_realms_events`。快捷指令只填字、不送出；原輸入不空時指令附於末行。裸稱完整事件名亦可觸發，但一般對話提及或前輪內容不會觸發。

## 轉換

編譯器提取原文六步節奏、六種事件類型、下／中／上界場景範例及特殊注意。provenance 記錄 11 條原文 SHA-256 與排序後 profile SHA-256；重跑遇到來源變動要求重新核對。原始壓縮檔與完整輸出格式指令不發布。

只生成一個放在最新玩家輸入前的短暫提示，不修改既有穩定提示前綴，不建立額外模型請求。每輪至多一種事件；多個明確指令選第一個。提示上限 1800 字元，目前各界域約 500–650 字元。

所在界域取已確認的三界修煉路線。未知或鬼界不假定下／中／上界；現有作品設定優先於原文場景靈感。六步法可以跨多輪推進，避免一輪走完、替玩家抉擇或自動宣布成功。時間跨度未指定時停在選擇點，突破意圖不等於結果。提示不發放資源、寫任務／NPC／時鐘或改修為；只有故事明確發生的事實經原有追蹤更新。
