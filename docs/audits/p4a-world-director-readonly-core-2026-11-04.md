# P4 世界事件與連續性審閱

「故事總覽」中的「世界事件與連續性審閱」預設收合。完成一般故事回合後，可展開核對最近一輪的到期排程與時間線變動。審閱使用瀏覽器內已有的世界時鐘與故事原文。

## 回合與證據

- 在一般故事送出前擷取世界時鐘快照。既有世界狀態流程返回後，核對原本的故事、設定、對話前綴、相鄰的玩家與助理訊息，以及供應商完成狀態。回覆截斷、遭阻擋或已過期時，該輪無法成為審閱來源。
- 事件標籤須唯一，並和一筆仍有效的已確認記憶及其原文中的獨立純文字行完全相符。來源 ID 和簽章均須符合目前分支。對於受限事件，所有當前發言角色都須有最新、可追溯的目擊或告知證據。公開事件可直接以已確認原文為依據。
- 到期排程顯示為候選，並附對話訊息序號。連續性檢查辨識時鐘倒退、已關閉事件重開、期限變動與待處理事件消失。排程由待處理變成已關閉時，審閱提醒玩家核對原文是否交代了結果。單有事件名稱或來源 ID 無法確認事件已發生。
- 每個故事僅在當前頁面記憶體內保留最近一輪的快照。展開時會重新驗證來源和時鐘。回溯、改寫、切換故事、重載或時鐘改變後，過期結果會失效。

## 範圍

審閱結果只在玩家展開時呈現，沿用既有世界狀態更新與存檔流程。審閱本身沒有模型請求、提示詞注入、存檔寫入或事件執行。這一版檢查結構化時間線與可追溯的事件原文。故事散文的語意矛盾、模型輔助判斷及確認後修正可另行評估。舊存檔沿用現有 schema。

## 驗證

核心測試覆蓋候選排序、時鐘倒退、排程關閉與知情邊界。以 120 輪資料測試舊來源、角色別名、傳聞、重複來源、回溯、改寫及撤回。瀏覽器以實際送出及世界時鐘附錄驗證桌面和手機的鍵盤操作、證據顯示、截斷後失效、幕後資訊遮蔽與審閱前後資料一致性。
