## 本次從原始碼確認的缺口

1. 管理後台主要操作都堆在單一長頁：登入、玩家、儲值、Hosted 上游、作品上架、使用統計；沒有快速前往不同工作區的原生導覽。創作室已有六階段定位，但不能直接把創作流程套到管理後台。
2. 玩家名單表格 `min-width:760px`，手機必須橫向捲動才能看到最後方「選取／用量／停用」等動作。原列表容器沒有 `tabindex` 或明確的捲動指示；同頁 API 用量明細早已具 `tabindex=0` 與捲動標籤。
3. 玩家列表的操作按鈕在桌機樣式只有 `padding:7px 10px`，並未保證 44px 觸控區；管理頁登入／查詢／點數／上架的動態訊息缺乏一致 `role=status` 與 `aria-live`。
4. 「作品上架管理」已有匯入、驗證、作者授權和建立 PR；只需讓文字清楚表達「創作室匯出 → 管理頁驗證 → PR → 合併部署後公開」，不需增加平行發布流程。

## 修正範圍

- 頁首新增原生快速導覽，連結既有登入、玩家、點數、發布、統計區塊；Hosted 路由連結在後台真正顯示該區塊後才出現。使用水平可捲導覽避免 320px 擠壓，維持鍵盤 focus、44px 點擊區和區塊 scroll-margin。
- 玩家列表新增可聚焦、明確標示水平捲動的容器，以及手機提示；表格欄位、按鈕、操作確認與 Worker 呼叫完全不變。管理頁按鈕以 44px 作為觸控舒適度目標，焦點使用夜灣暖金語義。
- 常用管理結果區增加動態狀態語意，使鍵盤／輔助閱讀者能收到操作完成或錯誤回饋。
- 作品上架說明更新為與創作室一致的正確交接路徑；不改原有作者署名、授權、發布判定或角色卡的 Schema。
