# 記憶 P2c：有證據的持續相關性輔助排序

基準 e48c826b99627e7c89a163b26a74cbabea7be28d。本輪只在既有 opt-in hybrid 模式，把現有可驗證的後續角色知情更新與公開事實更正作為有限重要性代理訊號。不是判斷所有事件的重要性，不推測人物心理，不按題材、承諾詞彙、年齡或重複次數打分。

先通過原有來源、知情、相關性、撤回、排除等條件，且本輪查詢詞實際命中可見 claim。私密事件未撤回、所有當前角色的最新共同認知都具有有效 afterEvent=true 的目擊/告知更新時可得 1 分；傳聞/推論不給分。公開更正必須為有效 confirmed 公開事實，且 supersedes 指向同一分支中更早的有效 confirmed 公開事實；隱藏、無效或重複 ID 的目標不得作排序依據。兩種訊號不累加。不新增候選，不改變認知模式、客觀事實、來源、注入內容與持久化資料。

只在原有分數及 P2b/P2a 同分時先於時間排序決勝，原 lexical/fulltext/RRF 仍保留。上限 4 筆/2400 字元，不增加 API、模型、設定、額外儲存或任何付款服務。預設非 hybrid 模式不變。core 版本 11→12。

新增固定合成測試含 4000 則間隔訊息（2000 輪）、舊角色更新、公開更正、五筆較新干擾事件、傳聞、僅標籤、錯角色、失效／改寫原文、隱藏／歧義更正目標、去重、預算及 state 不變。76 案原 oracle 保留，兩份報告只同步 core 雜湊，待 CI 重跑證實，並非新實測報告。

限制：仍只適用於有索引且相關的事件；未更新的舊承諾不一定優先，無關、未索引或被 1000 事件容量移除的歷史不會因此找回。4000 則合成間隔不等於真實長篇故事生成驗證，Token/延遲/模型品質待 P3 量測。回退本 PR 無資料遷移。
