# BAO/LAB A+ 設計紀錄

## 已確認的方向

- 保留 A 的紫黑夜色與角色海報主視覺。
- 採用 C 的明暗對比與材質層次：暖紙、書籤、頁碼、章節線；不做滿版泛黃羊皮紙。
- 「包包夜讀書房」是輕量品牌故事。包包是留燈的陪伴者，介面仍使用「開始故事」「繼續故事」「故事書庫」等清楚名稱。
- 暖象牙白用於閱讀，杏仁與暖金用於燈光與少量行動提示。薄荷綠保留系統狀態語意。
- 目前作品量少，暫不新增精選作品分類、排行榜或大型推薦牆。

## 本次落地範圍

首頁依序呈現品牌情緒、現有小型角色展示、閱讀示例、書庫與跨裝置接續、最後的開始入口。

閱讀示例以暖紙、細微表面層次、書籤與頁碼承接夜色；明確標示為示例，不冒充角色實際開場。書庫章節同樣標示為示例，按鈕開啟使用者真正的故事書庫。

跨裝置說明維持產品實際行為：先保存在目前裝置，可連結自己的 Google Drive，再於另一裝置同步；API Key 不同步。首頁入口只打開現有同步面板，不自行授權或上傳。

閱讀介面沿用單一「閱讀／工作室」切換，預設進入閱讀。狀態可獨立開啟，記憶／Token／成本統計收在工作室。已移除的舊沉浸模式不再是測試依賴。

此版本完成首頁的 A+ 材質與敘事節奏；不代表所有設定頁、工作室或作者自訂 HTML 都已全面重製。作者自訂的故事 HTML 保留原有內容與風格。

## 驗收範圍

- 320、390、1280px：閱讀示例不溢出、書庫和同步面板可開關、收尾 CTA 到作品頁。
- 320、390、900、1280px：狀態可開關、閱讀與工作室可往返、工具重繪不關閉抽屜、不修改故事訊息。
- 390、1280px：首頁、作品、角色詳情、書庫與閱讀畫面截圖。
- 直接更新 main 時也執行 editorial visual workflow，避免視覺流程只在 PR 測試。
