# 時空之門｜齊格飛

來源是作者提供的夜灣 JSON、五段 MMD 面板與 TheAges_1.png。原檔保存在 `docs/sources/the-ages/`；封面原圖在 `assets/characters/the-ages/cover.png`。

## 保留與適配

- 101 則世界書內容、關鍵字、人物與支線逐字保留。原引擎 DATA 表與遊戲函式有回歸比對，沒有改戰鬥、掉落、職業、價格、時間或任務邏輯。
- 五段腳本先還原成完整程式，再改寫宿主 I/O；不依賴連鎖替換、inline onerror 或 eval。`scripts/build-the-ages.py` 可重建卡與側掛 Regex。
- 使用既有 opaque iframe，不給同源權限；CSP 仍禁止連網。Regex／引擎不放進模型上下文。
- 作者指定的分類為世界／一般，署名連到現有作者 `chicofy`；作品目錄與作者頁可找到它。
- 原作者說明中的 hc-collapse 轉成 details／summary，hc-btn 的 send 內容由原生行動建議元件填入草稿。其餘敘事及數值規則保留。

## 玩家操作

在故事工具的自訂介面進階設定啟用「允許互動腳本」「保留互動介面」。手機若面板收合，點聊天區上方「自訂介面」展開。

另有本作品專用選項：「允許讀取遊戲回執」只給本故事 assistant 的 TGA／TGX 標記、最近一份 TGS 劇情存檔及手動回合計數，不給原始對話或玩家文字；「保存冒險進度」另存本故事面板資料，最多 256 KB，包含目前角色、五角色庫與面板開關。

面板動作需要 AI 演出時，最多填入 16,000 字指令，由玩家自行送出；一般 draft 仍限制 500 字。原引擎本來允許不呼叫 AI 的一般行動仍由面板自行結算。沒有自動消耗 API 的新入口。

## 存檔與隔離

`authorGame` 是故事備份的獨立附件，以目前 GameState 物件隔離，並綁定 `shikong-zhimen`。不混入 GameState、提示詞或世界狀態。還原時僅接受三個既定存檔鍵與有界字串資料。跨故事不共用角色庫；同故事最多五角色及寄存機制仍沿用原作。舊 Luna 存檔可用原面板的存檔碼匯入目前角色；原匯出碼不包含完整夜灣聊天與世界書，跨裝置建議同時匯出夜灣完整故事備份。

未授權保存時只在目前 iframe 暫存，介面會提示先匯出。變更授權會重建 iframe，應先匯出尚未保存的遊戲進度。停用授權不會刪除舊備份。

## 驗證範圍

`tests/the-ages-card.cjs` 比對原作者資料與函式、101則世界書、匯入及目錄；`tests/e2e/the-ages.spec.cjs` 驗證開局、回執、跨回合、存檔與還原、教學跳過、移動、原存檔碼、權限與手機面板。測試用模擬 assistant 回執，不呼叫付費模型。仍需部署後確認實際模型遵守原作 TGA／TGX／TGS 輸出契約，不能由瀏覽器測試保證所有模型表現。
