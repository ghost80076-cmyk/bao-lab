# 夜半紙嫁｜雨宮澪：夜灣適配

來源：作者提供的對話、《夜半紙嫁_雨宮澪_即貼角色提示與開場白.txt》與《夜半紙嫁_雨宮澪_外部平台角色設定初稿.docx》。已讀取兩份原始內容。

作品保留金紙店繼承人、28歲影像修復師亡靈、失落母帶、恐怖與親密並存、百相嫁衣的慾望增幅／誓約／脫下後記憶延續。其他女鬼仍留待作者獨立世界書補充。

男性向單角色設計落在魅力自覺、人格反差及慢慢形成的獨特關係；黑羽提供自主日程與角色不依附玩家的設計參照，林雨萱提供生活持續前進、事件留下後果的參照。不移植兩作人物、既定悲劇、攻略階梯或好感度數值。

主設定維持人物核心與兩種驅動；紙行、母帶、詛咒、嫁衣拆成四則關鍵字世界書。世界書召回是模型上下文選擇，不代表玩家或角色已知。真相透過故事逐步揭露。

## 原生前端

- 四個原生頁籤：此刻、線索、紙行、你們之間。
- 內部情緒、關係認知、自主目標、未揭露場外行動、詛咒及嫁衣真實狀態設 `visibility: internal`，不綁到可見UI路徑。
- 姓名在初見時未知；婚服穿戴、契約與效果在玩家確認前也維持未知。
- 開場採原生 noir 結構，不加固定選項，保留自由輸入。後續不強迫每輪選單。
- 只在玩家實際看見時，紙行紀錄與錄影片段使用兩組可選標記。獨立 Regex sidecar 僅做唯讀排版，不執行JS、不寫狀態、不改故事紀錄。原文無標記時正常顯示。
- 封面是原創紙行／電視／母帶題字 SVG，屬本版視覺包裝，非雨宮澪外貌定稿。未借用其他角色照片。

## 驗證

Creator 的角色結構與四則世界書檢查通過。針對卡片正規化、可見路徑、內部狀態、原文保留與Regex插入內容轉義作單元驗證；桌機與手機測試已加入PR的Chromium CI；本機瀏覽器安裝包下載無效，未完成本機E2E。測試使用離線API替身，檢查開場、分頁、狀態更新與隔離紀錄排版，不消耗模型額度。

未執行實際模型長對話模擬，因此人格與長期情感表現仍需後續真人遊玩校準；UI測試不宣稱保證LLM逐輪正確演繹嫁衣或情緒。
