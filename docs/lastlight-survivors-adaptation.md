# 末日餘生｜特性求生錄

班長《末日求生者-(肉鴿、正負面特性)》重構，ID `lastlight-survivors`。

保留五種世界、8點、13種職業、23項正面、26項負面特性、技能、探索、製作、同伴、基地、每日結算與角色死亡後世界延續。封面沿用作者網址。

新增的共用選項組提供真正的前端扣點／返點、互斥、背景相容性檢查、合法隨機構築與開始前攔截；全局功能僅對宣告選項組的作品啟用。健康、耐力與負重的有限初始化加成由前端原子套用一次，技能、職業包展開及持續求生仍由模型結算。百分比對基礎值的修正以相加處理；不是宣稱有完整戰鬥計算器或擲骰服務。

五種世界各有獨立開場、已知威脅與四個起手草稿，依選定背景在建立故事時替換場景。初始數值不先扣耗時或給首戰勝利；職業物品保留在未開包物資中，第一次使用才展開，避免重領或包裹與內容雙算。世界書包含五背景與兩項製作／基地參考；常駐提示保留真正每輪需要的規則。

改動有明確玩法目的：飽食／水分歸零先進入危重狀態，不瞬死；對話不自動耗半小時；一次經過時間只結算一次；事件依風險窗口而非每口飲水抽災難；骰子成功方向統一，沒有真骰就標敘事判定；基地與裝備能減輕壓力，不讓敵人同步升級抵銷成果。社交／性格缺陷影響難度與他人反應，不直接代替玩家選擇；角色死亡不把前代知識、仇恨和技能直接搬進新角色。

介面有六個分頁：此刻、人物、物資與基地、世界、成果、行動。桌面用既有三欄框架，手機回到既有分頁與抽屜。作者 Regex 僅排版明確的首幕標記，不掃描全文、不改模型提示與狀態；未使用外平台 hc-* 或自製網頁腳本。

本次不加入持續生理計算器、世界重建選單或自動死亡換角介面。換角仍由對話承接8點配點；其他故事的讀檔／分支功能不受作品文字限制。成年人關係採非露骨敘事；不轉製原稿隨機提高露骨等級的設定。外部封面未內嵌，未進行付費模型長程對話。

驗證包括200組固定種子合法構築、超支／互斥／背景／數量、無效配置原子性、重複套用、五世界開場、前端數值與資料路徑、世界書召回及Regex。另以現有瀏覽器測試檢查手機操作、草稿保留、單選職業、開始攔截和科幻開場。
