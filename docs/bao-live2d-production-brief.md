# BAO/LAB｜包包人形 Live2D 製作交付規格（規劃文件，尚未建模）

## 角色設計不可變更

- 第一版人物立繪為**唯一人形母版**，不是設定板中後續重繪的黑色街頭外套造型。需要原作者提供可商用、可改作與可公開展示的授權及可取得的高解析圖層原稿；若僅有扁平化圖片，先依母版重新繪製分層原畫，不可假稱已有可動模型。
- 第二版作為**肉包本體、Q 版、表情差分**參考；第三版只參考設定板排版。
- 奶白蓬鬆短髮、淡粉微捲髮尾、粉紫眼、黑粉蝴蝶結、黑／粉 X 髮夾、肉包頭飾、第一版蓬鬆大袖與白／粉／黑服裝、飾牌與鞋飾均需保持一致；女性外型、中性氣質。
- 肉包與人形為**同一角色的兩種形態**；圖中同時出現兩者僅是視覺示意、道具／造型符號，並非新增獨立寵物人格。

## 繪師交付：可供 Cubism 匯入的分層 PSD

以中立正面姿勢繪製，層名清楚、無背景、色彩空間一致；每個會移動的物件保留被遮住的完整繪畫範圍（例如眼球後面的眼白、髮絲後面的額頭、袖子後方的手臂）。請依實際建模需求調整分層細度。

| 類別 | 至少分開的部件 |
| --- | --- |
| 臉部 | 臉輪廓、耳、鼻、左右眉、左右眼白、左右虹膜／瞳孔／高光、上下眼皮／睫毛、上／下唇、口腔／舌、腮紅與表情件 |
| 頭髮 | 後髮、左右側髮、前髮束／瀏海、翹髮、粉色髮尾，可擺動髮束獨立 |
| 配件 | 肉包頭飾、蝴蝶結及其垂帶、兩枚 X 髮夾、頸飾與吊牌分離 |
| 上身 | 頸、軀幹、左右上臂／前臂／手、蓬鬆袖子及袖口、內層衣服、外套／裙層、可擺動緞帶 |
| 下身 | 裙擺層次、左右腿、襪子與飾件、左右鞋及肉包鞋飾（依展示範圍取捨） |

**檢查點：** 開眼／閉眼、張嘴／閉嘴、頭部小角度轉動時不能露出 PSD 原本被擋住的空洞；左右配件避免只有一張合併圖。

## 建模師交付與動畫最小集合

- 交付 Cubism 原始專案 `.cmo3`、必要的動作原始專案及可於 Web 播放的 `.moc3`、`.model3.json`、貼圖 PNG、必要的 physics / motion / expression JSON；使用的 Cubism SDK 版本及素材授權另附說明。
- 最小參數：頭角 X/Y/Z、身體角度或輕晃、左右眼開合、眉毛、眼球 X/Y、嘴開合及嘴型、呼吸；頭髮／蝴蝶結／吊牌物理擺動為第二層。
- 最小動畫：待機、自然眨眼、開心、困惑／害羞、摸頭反應與變身前後的過場（可先採畫面切換，不應宣稱單張圖有真實變身骨骼）。
- Web SDK 驗收：正確載入 `.model3.json` 與所有資產；玩家點按／鍵盤操作可觸發表情；隱藏時停止繪製、手機可關閉動畫、遵守 `prefers-reduced-motion`；模型載入失敗時退回目前的靜態人形或 SVG 肉包。
- **資安邊界：** Live2D 展示程式不取得使用者 API Key、故事、記憶或對話；不載入第三方未知作者腳本；公開部署前確認 SDK / 模型商用條款。

## 網站階段界線

第一階段已使用前端 SVG 實作肉包浮動、眨眼與互動；人形切換目前是靜態 WebP **預覽**。上述 PSD、Cubism 工程與 Web SDK 人形模型尚未交付，不得把目前的網頁演出標示為正式 Live2D。
