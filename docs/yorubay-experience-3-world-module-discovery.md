# Experience 3.0 · 第十輪：世界模組管理查找與資訊分層

2026-10-15；承接 #650–#658 已部署版本。

## 背景
玩家要進行劇情，首先是閱讀和操作故事；世界模組管理是進階功能，不應該一打開就被背包、技能、境界、關係、追蹤頻率及 Context 技術說明塞滿。

## 本次 UI/UX
- 「官方模組」增加名稱搜尋，以及「全部／已啟用／可新增」篩選，顯示匹配項目數及零結果提示；預設仍保留完整列表，避免破壞既有作品和三界玩法入口。
- 查找只改 DOM 顯示，原本 checkbox 草稿、模組設定與「套用到目前故事」行為不受影響。查找關鍵字及篩選在一次開啟期間保留，即使勾選後重新渲染也不跳回全部。
- 「Context 原則」「追蹤頻率」集中至「進階說明」；輕鬆／標準玩家預設收合，專業玩家展開。原本文字完整保留。
- 模組視窗與操作控件採用既有夜港／晨霧／暮玫色票，處理亮色主題過去深黑卡片的割裂。
- 保留目前模組順序、官方範本、我的模組、重設與套用四個既有入口；手機現有順序與置底操作不變。

## 驗收
- 390px 與 1280px 找得到「三界修煉」、可切換篩選、正確處理空結果。
- 勾選但不套用不能修改已儲存世界設定；關閉重開仍保留舊值，按「套用」後才生效。
- 輕鬆／專業控制進階說明預設開合；晨霧／暮玫計算背景色一致，不產生整頁橫向溢出。
- Core、Fast Browser E2E、世界模組與遊戲狀態回歸全部通過才合併。
