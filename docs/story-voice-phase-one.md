# 語音系統 P0：免費裝置語音與文字輸入

基準 #986。獨立的選配語音工具，不是新 Story Engine。入口在既有控制中心（搜尋「語音工具」）及桌面工具區，不占用手機輸入列，開啟時才讀裝置聲線，沒有自動下載、麥克風啟動、播放或模型請求。中／日／韓／英按裝置實際可用語言，缺少聲線明確告知，不默默 fallback。預設僅選本地聲線；明確選遠端聲線需每次確認。語速／音高／音量及作品 ID + NPC ID 的聲線設定保存在本機，最多 100 筆，無音訊、金鑰、對白或故事資料。語言選擇不等於翻譯。

TTS 僅手動確認的文字：最近 20 則 AI 回覆可提供引號候選，HTML/標記不猜測，候選不證明說話者或台詞；玩家指定角色及台詞才播放。沒有旁白自動朗讀、結構化 AI 輸出契約或額外 token。保留後續作者 opt-in 標記及語音演出模式的空間。

STT 是輸入法：玩家同意裝置／瀏覽器可能連網的辨識服務才啟動麥克風，預覽可改，填入時保留原文字，原草稿或故事／章節變更拒絕合併，有待送圖片亦拒絕，永不自動送出。不支援 API 時使用裝置鍵盤語音輸入；不能假裝離線或原生音訊理解。關閉面板、切換故事、離開頁面、背景或逾時停止服務。官方文件：https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API

後續 P1 聲線包/作者契約；P2 開源本地模型；P3 Phone 收件範圍及語音訊息；P4 BYOK/原生音訊理解；P5 通話。所有費用與運算由玩家自帶，無夜灣 TTS/STT 服務器。P0 不保存音訊或改動備份、Drive、分支、世界狀態、API、燈火、提示詞。測試為 mock 瀏覽器語音服務，真實聲線、麥克風、手機和 OS 權限仍須實測。回退移除入口及模組即可；本機設定獨立，不影響既有存檔。

## P1a：裝置聲線設定包

格式 `yorubay.voice-profile` v1，engine `web-speech`；只接受 language、voiceURI、rate、pitch、volume，限制 16 KiB 檔案、範圍與欄位，拒絕未知引擎、版本、憑證與額外欄位。聲線識別只與裝置清單匹配，絕不作 URL 存取。匯入僅預覽目前角色，需另存；異步讀取時切換角色或調整設定將放棄過期匯入。不播放、不下載模型、不包含台詞或錄音。作者對白契約、模型包與聲音複製留待獨立 PR。

## P2：自訂 STT 接入（不含模型研發）

#993 研究 PR 已依產品決策關閉，研究分支保留，不合併。此階段只在既有語音工具增加選配的 OpenAI-compatible multipart `/audio/transcriptions` 接口（完整 URL、模型 ID、選填獨立 STT API key）。預設仍用裝置語音辨識；繁中 zh-TW 優先，傳送相容接口語言代碼 zh，輸出原樣供玩家編輯，不承諾服務一定輸出繁體。玩家自行申請 API 或架設相容服務，需可接受瀏覽器錄音 MIME、HTTPS／loopback HTTP、CORS 及瀏覽器本機網路限制。並非所有 STT 服務都相容，不保證自架服務可直接連線。

設定及金鑰僅在本次語音工具開啟期間存在，不保存、不匯出、不使用 RP 金鑰；玩家每次明確同意才取得麥克風權限，按停止辨識才將錄音直送指定接口。錄音最長 60 秒、最多 8 MiB；取消、逾時、關閉、離開及失效會釋放錄音並取消請求，禁止重試或自動 fallback。辨識回應有大小限制，只接受 JSON text，不進故事歷史、記憶、備份、診斷或 Phone 音訊資產；仍使用既有預覽及填入草稿檢查。取消已送出的請求不保證服務端停止處理或免收費。此 PR 不含一般錄音上傳、角色配音、語音通話、本地模型下載、後端代理或新依賴。

驗收：Node 契約及 Playwright mock 測試；實際第三方服務的 CORS、音訊格式、費用、實體手機麥克風需玩家選擇服務後獨立驗證。未設定或連線失敗均可繼續打字。回退：移除自訂 STT 選項及相關程式，裝置 STT/TTS 維持不變。
