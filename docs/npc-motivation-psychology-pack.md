# 人物心理深度｜選配敘事強化包（2026-11-06）

## 定位

在「今晚的故事 → 沿途風景」新增「人物心理深度」，預設關閉，與配角日常、伏筆回聲等選項共用既有 `narrative.storyExtras` 清單、正規化、保存、提示詞組裝和狀態摘要。設定 key：`motivation`。

本包僅補強 NPC 的動機慣性、策略調整與情感矛盾，不重寫世界模擬 Prompt、人物設定、MOD、狀態追蹤、玩家授權、Canon、NPC Timeline 或 P4 世界導演。系統對資訊隔離、來源確定性及已確認事實的限制仍優先。

## 生效原則

- 只在玩家明確勾選後，透過既有的穩定故事偏好 Prompt 生效；未啟用或舊故事沒有設定時，不產生額外 Prompt 字元。
- 角色已有的目標與重要承諾不因單次受挫或轉場就憑空消失；新資訊、風險、代價、明確拒絕仍能令其調整或放棄。
- 公開態度、私人需求與即時情緒可以矛盾；不預設所有人物都算計，不要求每輪心理博弈或事件。
- 意圖、推測與尚未執行的計畫不得視為已完成事件。私人心理資訊的呈現必須服從既有視角／內心戲設定。
- 不新增每輪 LLM 整理、獨立動機資料庫、暗中修改狀態、計價行為或實際溫度 API 參數。

## 限制和後續驗證

此版本是模型行為提示，不保證模型在長篇劇情中永遠記得目標；其長期表現依賴既有歷史、記憶與故事狀態。P4 目前仍是唯讀世界事件審閱，不提供自動 NPC 決策。若後續要結構化記錄目標／阻礙／策略變化，須另案設計明確來源、人物知情權限、回溯與分支驗證，不能把模型推測直接存成已確認事實。

驗證入口：
- `node tests/narrative-settings-core.cjs`
- `node tests/narrative-prompt-pipeline-core.cjs`
- `node tests/e2e-group-runner.test.cjs`（依既有群組）
- `tests/e2e/narrative-cache-preservation.spec.cjs` 透過 Fast Browser E2E 執行

回退：移除 `extras.motivation` 與文件／測試即可；正規化會忽略舊存檔裡的未知 `motivation` 項，不需資料遷移。
