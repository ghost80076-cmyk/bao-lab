# 事件記憶召回與角色知情來源

本 PR 對應記憶研究比對與「角色知情表」討論：沿用 Local-first／BYOK、智慧摘要、Canon、Context Pack 與完整聊天原文，不建立第二套雲端記憶服務。不與 #684 的公開故事歷程／收藏混用資料；私密事件索引不進入公開歷程。

## 本次完成

- 智慧摘要原本的呼叫同時輸出可選事件資料，Gemini 使用包含 episodes 的獨立 JSON schema。每次最多收 12 筆；舊模型只回四類摘要仍可使用，格式修復的結果不建立事件。
- 本地 `state.episodicMemory` 保存事件、原文明說的故事時間、人物／關鍵詞、來源 message ID 與內容指紋。與完整故事 state 一起走現有 IndexedDB 存檔、快照與備份，不另建資料庫。上限 1,000 筆，超過時移除最舊索引；聊天原文不刪除。
- 中文雙字片段、英文詞、模型提取的同義詞與人物關係提示提供低成本召回。沒有 embedding，也不聲稱能理解任意同義改寫。輸出最多 4 筆、事件區塊合計最多 2,400 字元（不是 Token），另有固定說明文字。
- 每個知情條目記錄 actor、witnessed／told／rumor／inferred、實際認知 claim 與原文來源。缺少來源不算知情。預設 restricted，只有原文明確公開的 confirmed 事件可無角色條件召回。
- 單角色模式使用角色名稱與明確在場 NPC；世界模式只使用 presence=present 的 NPC，不把作品名稱或提及的人物當作在場角色。多人請求只送所有列入角色共有的相同 claim。寧可漏召回，不在同一請求裡混入不同角色的私密認知。私密事件不附帶角色未必知道的客觀事件文字、時間或客觀確定程度。
- 來源缺失或內容變更則不召回；只有來源順序較晚且明確 confirmed／retracted 的 supersedes 更正可以遮蔽舊結論。更正本身在分支中不存在時，不會刪除那條分支的歷史事實。
- 以本輪既有 prompt 的內容做精確字串去重，減少與摘要、Canon、近期原文重複的 claim；不宣稱語意去重。
- 回憶置於最後一則 user 訊息內，位於固定前綴、記憶與歷史之後，不改動它們的內容。快取命中仍以供應商 usage 為準。
- `config.memory.episodicRecall=false` 停止提取及召回；full 模式不重複召回。事件變更但摘要文字未變時，仍觸發原有存檔。

## 成本與相容性

檢索不新增 API 呼叫；事件提取會增加既有摘要請求的提示與輸出 Token。本次維持原本摘要頻率、修復與失敗處理，沒有強制每輪摘要。近期最多 8 筆簡短事件 ID／文字提供更正線索，並非整個索引重送。舊存檔逐步從之後的摘要建立索引，不自動付費重掃歷史；若之前已壓縮的事件沒有索引，本版不保證找回。

完整 state 是持久化來源；召回結果每輪重新計算，不寫全域 localStorage，不跨故事混用。因沿用完整 state 備份，玩家備份也可能包含自己的私密劇情記憶。

## 已知限制與後續

這是「事件索引檢索層」的邊界，不是整個模型的秘密隔離保證。原有摘要、Canon、作者設定與近期聊天仍可能包含其他角色的資訊；單次多人生成也無法做到模型內部真正互相隔離。Canon 既有知情文字未轉成結構化權限；本次不自動改寫玩家已確認的 Canon。

模型判讀來源、公開性、角色名稱、知情內容與更正仍可能出錯。程式驗證 ID 與原文指紋，不等於證明事件描述必然為真。名稱採精確比對；未知別名可能漏召回。presence 快照可能落後於本輪進出場，較新的對話仍需模型遵守資訊流規則。

時間檢查是來源訊息順序及當前分支可用性，不是通用故事曆／回憶場景時間推理。較晚的歷史事實可能改變角色認知；本版只辨認明確更正，不自動替所有人更新信念。更正線索限近期 8 筆，久遠矛盾仍可能需要 Canon 整理。

後續依測試結果評估：更完整的角色身份／知情更新、Canon 結構化串接、記憶索引檢視與重建入口、可選本地 embedding。先以固定測試集量測漏召回／錯召回，再決定是否值得增加成本；不直接套用外部論文的成效數字。

## 驗證

`node tests/episodic-memory-core.cjs` 包含 200 輪前事件、無原關鍵詞的關係提示、同義詞標籤、無關查詢、虛構 ID、原文改寫、分支來源缺失、角色未知／傳聞／多人不同認知、公開事件、較晚更正、去重、字元預算、state 序列化、同次摘要提取、Gemini schema、停止開關、動態注入位置及切換故事的晚到回應。

另執行既有 helper context、摘要生命週期、模型選擇、Canon、prompt cache／orchestrator、備份與故事資料庫回歸。這些是可重現合成測試，沒有真實玩家長篇召回率、模型費用或服務商快取命中實測。沒有新增畫面。
