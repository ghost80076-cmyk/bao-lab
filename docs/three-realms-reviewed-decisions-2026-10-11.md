# 三界遷移採用決策

本次把 9 條來源明確分類為「已審閱、未採用」，避免把沒有實作的原文規則一直列成即將上線功能，也不把它們算入已遷移功能。原始來源沒有被改動；正式程式只發布索引、雜湊與採用決策，不發布這些指令全文。

| 來源 | 決策 |
| --- | --- |
| 24 | 不加入一般原創人物包 |
| 38–40 | 不建立自動親密數值、開放度轉換或離場亲密事件引擎 |
| 52 | 演員設定不能成為覆蓋作品條件與事件後果的全域許可 |
| 53 | 戲外演員身份不能覆蓋戲中人物年齡 |
| 55 | 未加入一般三界快捷指令 |
| 56–57 | 未轉成全域寫作提示、一般風格包或依玩家性別自動切換的風格 |

這些是採用範圍決策，不是著作權或所有權問題。一般三界功能沿用既有作品設定、人物自主與平台界線。

尚有 4 個功能 follow-up：33 的固定比例／自動導演、36 的離場導演、42 的自動選角，以及 172 的完整作品呈現評測。自動導演遵循既有實驗文件，沒有因改寫來源就繞過代表性作品評測。

當前分類合計 191：115 個世界事實來源、25 個原生提示來源、31 個原創人物原型、5 個原生規則對照、4 個修煉契約來源、1 個狀態範本、1 個待評測規則、9 個已審閱未採用來源。5 個原生規則中 33 和 42 為部分支援，狀態範本也保留 follow-up。正式事實包仍為 45 個、752 章。
