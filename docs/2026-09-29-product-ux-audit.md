# 2026-09-29 產品驗收與 UX QA

## 驗收基準

產品核心：故事優先。玩家的主要流程應是「選故事 → 接上 AI → 進入故事 → 長時間閱讀與互動」，技術層只在需要時出現。

本輪已實際走過正式站的新玩家與回訪玩家流程：首頁、作品詳情、快速建立、無 API 本機預覽、五輪對話、訊息工具、快速儲存、手動備份、離開、故事書庫、繼續閱讀、重新整理，以及帳號額度、Gemini、Custom Provider、LM Studio 的連線介面。

## 問題清單

| 優先級 | 頁面／流程 | 實際行為 | 預期行為 | 本輪處理 |
|---|---|---|---|---|
| P1 | 本機預覽／訊息工具 | `AI 改寫`、`重生成`、`行動靈感`仍可按，按下後才用瀏覽器警告告知沒有 API | 預覽模式只提供可用操作；需 AI 的操作應停用並說明原因 | 已修：預覽時停用三個 AI 操作，保留手動編輯與複製 |

## 風險界線

本輪只調整顯示條件、入口層級、快取版本與本機預覽按鈕狀態；未修改故事 schema、記憶核心、帳務扣點、Provider routing、存檔格式或 API Key 儲存規則。
