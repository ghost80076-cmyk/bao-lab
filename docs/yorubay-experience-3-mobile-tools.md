# Experience 3.0 · 第三輪：手機故事工具降噪

2026-10-15。承接已部署的 #650（三級操作／外觀偏好）與 #651（視覺一致性）。

## 玩家問題
舊手機工具抽屜同時展示十多個行動、技術名稱與重複入口。
因此手機輕鬆模式應先展示「要繼續玩的基本工具」，再依需求找完整功能。

## 新結構
- 第一眼四個明確動作：故事總覽、人物／事件、記憶、模型連線／切換。
- 較少用的上下文狀態、快捷指令、世界狀態、快速儲存、聊天外觀、置頂、支持夜灣收在「更多快捷操作」；專業模式自動展開，其餘模式由玩家選擇。
- 已有的「人物與故事資訊／搜尋對話」通用捷徑與手機快捷重複，手機只留一套快捷入口；完整工具分類與原始 click handler 保留。
- 全部故事工具新增搜尋框，輸入時直接篩選現有操作與分類，必要的折疊項目會暫時展開；清空搜尋後還原之前的展開狀態。
- 搜尋僅依 DOM 文字匹配，不讀取故事正文、使用者 API 金鑰或自訂作品設定。

## 非目標
不修改故事產生、狀態欄更新、模型與記憶 API、世界書回想機制、使用者存檔，亦不讓輕鬆模式失去專業工具。

## 驗收
- 375/390px 抽屜操作，初次四個工具可達；「更多」展開可找回全部原有快捷功能。
- 搜尋「快捷指令」可見目標；找不到時顯示提示，清空後恢復先前折疊狀態。
- 從抽屜繼續開啟模型、故事、世界資訊；沒有重複點擊事件或被切走的 DOM。
- 既有 Playwright mobile-reading-layout、mobile-composer-tools、story-quick-commands 等 E2E 跑過，搭配 Core／WebKit／Firefox 回歸。
