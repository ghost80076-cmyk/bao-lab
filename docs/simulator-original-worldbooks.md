# 通用世界模擬器與夏語涵補充

作者確認的用途：成人世界模擬器是通用的楚門世界、全局運作、文風和 NPC 模板；AV 用世界書主要補充夏語涵；AV 異世界所屬作品尚未搬入。這次不更動 AV 異世界內容，也不把它宣稱為完整作品。

## 搬入內容

`simulator-original-worldbook-library.json` 提供通用原文 189 條，以及夏語涵專用原文 30 條。通用書仍是一個文字列表項目，包含五類章節與八種可選文風。夏語涵補充是獨立的作品專用項目，含人物、片場 NPC、職涯任務與拍攝場景四章。

這次使用原始匯出中 202 條的通用來源（ID `59d9fbcd-d5f8-47aa-99fb-a101675230e4`）。AV 用來源的前 194 條逐字雜湊對應通用來源，避免重複載入；其餘 15 個專用來源處理成 30 個可召回條目，包含將同一來源中的不同場景拆開並補上各自的關鍵字。來源與排除情形全部記錄在 `simulator-original-worldbook-source-map.json`。

189 不等於原本 202 條全數原樣發布。六個涉及未成年性化框架的來源不發布；七個 LunaTalk HTML/XMLv3 渲染協定不移入夜灣提示。真人演員對應被移除，保留虛構人物模板原文；後宮模板中的兒童化類型列被排除。AV 補充另排除混合未成年性侵情境的企劃段落與真人選角連結。原檔不修改、不公開，也不以改年齡的方式搬入受限段落。

夏語涵的舊狀態欄來源對應到既有原生 UI 和 world_modules，不將舊 HTML 面板重複塞回提示。任務與職涯來源是補充素材，沿用作品目前的輕量職涯、角色身份、Action/Cut 與原生狀態欄，沒有另外實作強制技能樹或數值遊戲引擎。

## 生效方式

- 啟用通用書時，五條世界運作規則（原文 5181 字）以 `mode: constant` 完整進入第一段 system 的固定後綴。它們不參與動態排名，也不會被 4 條／2200 字上限截斷。
- 文風八選一，預設不選。整本開關不會啟用全部文風；選擇後持續每輪生效，直到玩家切換或停用。YA、NA、Romantasy、情慾奇幻、Erotica、Porn、章回體與純文字皆保留原文規範。
- 人物、題材、世界查詢及細節素材沿用關鍵詞召回。動態上限仍為每輪 4 條／2200 字。自動模式增加最近一則 AI 可見回覆作為訊號，順位低於最新玩家輸入與目前地點、高於一般在場人物，避免玩家說「繼續」就丟失剛進入的場景。場景模式與關閉可選召回仍維持既有範圍。
- 固定規則、文風皆須明確啟用，皆會計入 Token；一般劇情變化不改動固定前綴。固定規則總量超過 24000 字時明確阻止請求，要求關閉部分章節，避免悄悄截斷規則。
- 六個舊版的 62 條題材適配包標為 legacy；新列表不再展示未啟用的舊節選。舊存檔的已啟用項目及 pinned 原文仍可恢復，不會自動替換成新內容。
- 夏語涵新故事附帶四章的私有存檔快照；其他作品不自動套用。既有故事可在世界書選擇專用補充。通用書保持跨作品可選，沒有全站強制注入。
- 世界書快照數量上限由 64 調至 128，維持 3.5 MB 總量限制，讓較多章節並用時不會在讀檔時整個丟失。

## 驗證

```sh
python3 scripts/migrate-simulator-worldbooks.py /path/to/original.zip
python3 tests/simulator-original-worldbook-audit.py /path/to/original.zip
node tests/simulator-original-worldbook-core.cjs
node tests/worldbook-library-runtime.cjs
node tests/native-archive-catalog-core.cjs
```

原檔核對逐段驗證來源雜湊與保留範圍、194 條繼承來源去重，以及重新產出結果一致。無原始 ZIP 的 CI 仍檢查發布資料與來源對照的雜湊、覆蓋數量和排除範圍。瀏覽器測試覆蓋手機／桌機文風互斥、整本開關、搜尋、存檔恢復，以及原有異世界資訊隔離與文字列表排版。
