# Experience 3.0 · 第十四輪：故事擴充資料與權限資訊漸進揭露

2026-10-15，承接已合併部署的 #650–#662。

## 使用困擾
故事擴充卡片原本同時顯示功能名稱、用途、作用範圍、來源、保存位置、適用故事、啟用權限、授權細項和目前內容。工具雖完整，但初次進入的資訊密度偏高。

## 調整原則
- 功能名稱、用途、作用範圍及「管理」按鈕直接顯示；不隱藏原有入口。
- 把來源、保存、適用、啟用、授權集中在「來源、保存與授權」原生可展開區。
- 輕鬆與標準預設收合；專業預設展開；任何層級都能手動切換。
- 原有「目前內容」世界模組／作品設定清單維持獨立，不跟著新的 metadata 折疊；快速啟用／停用按鈕仍留在原位置。
- 來源、保存、適用、授權文字完整保留，絕不省略或改寫原有內容，也不影響作品 Regex 的權限或玩家安全決策。
- 使用夜灣三主題語義色票，鍵盤可操作，桌機與手機維持合適的折疊摘要高度。

## 回歸條件
- 在 390px 和 1280px，七類擴充資料仍保留原內容；輕鬆收合、專業展開可驗證。
- 開合 metadata 不變更 GameState，不改世界模組、Regex、MOD、模型 API 或上下文。
- 「匯出擴充設定／匯入擴充設定」和原本每張卡的管理入口不受影響。
- 需要 Core、Story controls、Fast Browser E2E、Firefox、WebKit 全綠才合併部署。
