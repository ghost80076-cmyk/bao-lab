# 通用世界模擬器：第一批

作者指定三本自有來源：AV用 209 條、AV異世界 251 條、防蒸餾題名版 202 條，共 662 個來源出現次數。精靈王不在此範圍。

本批只適配三本共同的六個非露骨題材來源：奇幻、玄幻、都市、熱血競技、末世、科幻。相同來源只發布一次，共兩個通用公開包、六章，追蹤 18 個來源引用。其餘 644 個出現次數保持待處理，不能解讀成已審完或已上線。

「通用公開」表示玩家可以取得並選用，不等於全站強制套用。預設不啟用；使用 world=general 保持跨作品可選，依明確題材詞觸發。全部採 scenario：方向尚未發生，不能覆寫作品 canon、導入新物種／能力或替玩家決定行動。

技能素材拆分規範影響：將巨大来源拆成可玩的題材參考；固定敘事比例、名作清單及原始成人情境未複製；未對來源原檔作刪改。這是功能適配節選，不是逐字完整搬運。

不重複 NPC 自主、資訊隔離、時間流動、記憶摘要、輸出格式或防護指令；以上仍由現有前端及全局層負責。作品專名與秘密、成人專屬資料不混入這一批公開包。

召回沿用既有前端排名、去重、4 章／2200 字上限和故事召回模式，不新增 LLM/embedding 請求。動態資料留在本輪尾段，不改穩定 system 前綴。原始文字未公開，source map 只記錄來源 ID、索引、雜湊及本批處理狀態。

來源核對：`python scripts/audit-world-simulator-general.py <原始匯出ZIP>`；測試：`node tests/world-simulator-general-core.cjs`。
