# 作者互動 UI 編排器（P1–P4）

入口：角色卡創作室 →「互動 UI」→「互動 UI 編排器」。一般閱讀作品不會自動產生 UI，需作者明確按「啟用互動 UI」。原有 UI 卡會載入目前設定。

## 可以做什麼

- 新增、複製、刪除與排序面板、區塊與項目。
- Panel ID 自動產生，可修改；改名同步更新布局引用，刪除前提醒並清除相關引用。
- 基本組件：狀態條、數值資訊、清單、行動按鈕。可設定資料來源、文字、數值範圍、筆數與空狀態。
- 面板／區塊提供專用把手拖曳排序，面板、區塊與項目都有上移／下移，結構按鈕也支援 Alt＋方向鍵。完成排序後保留選取與鍵盤焦點。
- 桌機並列結構、欄位、預覽；窄螢幕切換三個區域。預覽寬度切換改變 iframe viewport，溢出只在預覽容器內捲動。
- 共用正式 Panel renderer，以作品初始資料或明確標示的範例資料預覽。試算及範例值不會寫入作品狀態或故事。
- 既有購買／消耗按鈕建立器、外觀控制與新編排器共用同一份草稿。修改按鈕文字保留原生 effect；原生按鈕編輯未完成時，先完成或取消該編輯，再操作編排器。

## 保存與資料保留

編排器只有選取、焦點與預覽等介面狀態；持久資料直接保存在創作室的原始 `gameplay_ui`。不把 normalize 結果覆寫回草稿。草稿、JSON 匯出及加入本機角色仍沿用原流程；匯出格式維持 `gameplay.ui_schema`。

未編輯的 builder、theme、未知欄位及其他原生組件保留；編輯既有 UI 不會重設作者的顯示模式與主要舞臺。外觀控制只改作者實際調整的欄位，不會因讀取或編排就補滿預設值、移除自訂 surface 或未知主題欄位。未完成區塊可以儲存草稿；預覽暫時略過無效節點並列出診斷。匯出／加入角色庫前若有設定提醒，需明確確認。

## 這一階段的限制

資料卡、分頁、地點檔案與歷程的欄位編輯，以及預覽測試值已加入。完整多欄舞臺預覽尚未加入。預覽繼續沿用 [P0 的隔離與完成度契約](gameplay-ui-composer-p0.md)，不能代替正式多欄舞臺驗收。

瀏覽器 viewport 模擬不等於實機 Android／iPhone 鍵盤驗證。

## P2／P3 交接包整合

已將作者提供的 P2／P3 新增功能接入原有三欄編排器，保留 P0 的 builder／theme 診斷、Service Worker 與訊息隔離修正，以及 P1 的資料與焦點契約。交接包的累計 patch 沒有直接覆蓋目前版本。

- 八種原生組件均有欄位表單。資料卡選樣式時會帶入對應建議路徑；作者自訂路徑保留。
- 分頁可新增、複製、改名、刪除和排序；預設分頁隨 ID 改名同步，刪除時清掉引用。分頁內隱藏 tabs 選項，操作核心也拒絕巢狀分頁。
- 歷程支援 history／round_diff；地點檔案使用核心允許的路徑、場景來源和縮放列舉。
- 版面 preset 與現有面板 ID 下拉選單；編輯標準欄位時移除對應舊別名，其他未知 layout 鍵保留。
- 行動按鈕可編輯數值／物品結算、事件文字，並用正式 executor 在預覽資料副本上試算正常／資源為零的結果。試算使用目前欄位值，不提交故事或修改作品。
- 預覽測試值可調整數值、文字與陣列（以 `[]` 測試空清單），不會將作品標成未儲存，也不寫回初始 state。裝置切換顯示 Stage resolver 的實際結果。
- 設定檢查補上 effect 各筆、未知列舉、無效預設分頁、重複監看路徑等原因，提供前往相應欄位的按鈕。

驗收保留原有 P0／P1 測試，另外加入交接包核心測試及桌機／手機進階端對端案例。既有 demo 的 `gameplay_ui` 載入後原樣匯出，必須深度相等。

仍有限制：預覽只顯示單一面板，不呈現完整多欄舞臺；地點場景圖不載入。範本、初始資料帶入開關、全螢幕與對比檢查已在 P4 加入，見下節。


## P4：範本與作者預覽工具

「從範本開始」提供空白、RPG 狀態、商店與背包、圖鑑與任務、RPG 儀表板、終端機六種起手範本。按「預覽範本」只改預覽，不啟用互動 UI、不修改草稿，也不使作品變成未儲存。按「套用範本並啟用」才修改面板與版面；已有 UI 時會先要求確認，保留主題、builder 與未知根欄位。一次復原可還原 UI 及啟用前的顯示設定；復原到另一份作品的操作不會被保留。

範本只建立介面，作者仍需確認作品的世界模組、初始資源與引用路徑。預覽補出的範例模組與數值不會被加入作品。

「帶入作品初始狀態」預設開啟，可關閉以使用純範例。作品的 0、空清單、既有資料列與物件值會優先保留，缺少的值才補範例；測試值覆寫只在預覽生效。範例 meter 使用最大值的 60%。提供給 renderer 的模組定義只含 ID、kind、enabled。

「展開預覽」使用原本同一個 iframe，保持裝置寬度、測試值和圖片；Escape 或「返回編排器」會把預覽放回原位並恢復焦點。此功能仍是單面板預覽，不代表已完成正式多欄 Stage 的視覺驗收。

「場景測試圖」接受本機 PNG／JPEG／WebP，先在父頁縮小並轉成 JPEG，再以有來源、格式及大小檢查的 `set-image` 訊息傳給 iframe。僅用於 location_archive 的故事圖庫來源，不讀正式故事圖庫，不儲存圖片到作品／故事，不接受 URL 或 SVG。換作品會清除測試圖；重新載入同一份 iframe 可重送目前測試圖。原有 SW 的預覽 network-only 與純文字離線 503 保持不變。

對比檢查以正式 renderer 的實際 computed style 量色，檢查文字、次要文字與強調色對 surface 的對比，低於 4.5:1 時提醒。提示不改作者色彩、不阻擋草稿與匯出；對比通過也不代替完整視覺驗收。

驗證命令增加 `node tests/gameplay-ui-composer-p4-core.cjs` 及 `tests/e2e/gameplay-ui-composer-p4.spec.cjs`。瀏覽器視窗模擬不等於實機 Android／iPhone 鍵盤驗證。
