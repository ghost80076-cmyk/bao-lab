# Experience 3.0 · 第十二輪：全部故事工具選單主題一致性

2026-10-15；承接已部署的 #650–#660。

## 問題
夜灣已支援夜港、晨霧與暮玫，但「全部故事工具」的舊樣式仍把標題列、關閉鍵、部分折疊章節、存檔按鈕等固定為深色背景。亮色的晨霧模式中，這些局部控件與主題文字、其他對話框不一致。

## 本輪
- 只對非夜港主題（晨霧／暮玫）補齊工具選單外框、標題列、操作按鈕、章節、下拉選單與側欄分組的主題色。
- 使用既有 `--yoru-surface`、`--yoru-control`、`--yoru-card`、`--yoru-text` 等語義變數，不新增主題設定、全域覆寫，也不修改作者 HTML。
- 以 CSS 規則修正，沒有改工具分組、搜尋、快捷鍵、儲存、模型連線、故事記憶、API 或儲存行為。
- 資產版本遞增，避免瀏覽器混用舊樣式。

## 驗收
- 390px 手機、1280px 桌機，都可在原本故事狀態開啟「全部故事工具」。
- 連續切換晨霧／暮玫，標題列按鈕、各章節卡片與工具按鈕的計算背景色都符合當前主題變數。
- 搜尋與關閉按鈕保留，頁面不橫向溢出；返回夜港不改原本樣式。
- Core、Fast Browser E2E、手機閱讀和故事控制、WebKit/Firefox 全綠才合併。
