# Experience 3.0 · 第十一輪：故事總覽降噪與三主題一致性

2026-10-15。承接 #650–#659 已合併部署。

## 背景
故事總覽原本八張工具卡一開啟就全部顯示，內容包括模型、身份、記憶、狀態、上下文診斷、故事擴充、敘事與快捷指令。它是玩家最常進入的故事設定入口，不適合讓一般玩家首先面對八個並列選項。

## 這次只改顯示，不改功能
- 「目前故事」保留四個最容易理解且常用的直達項目：故事模型、玩家身份、故事記憶、人物／世界狀態。
- 其餘四項：敘事與描寫、快捷指令、上下文狀態、故事擴充，完整保留在「更多故事設定」原生 details 裡。
- 輕鬆模式初始收合，標準／專業模式初始展開；可手動展開及收合。其他頁面的入口不變。
- 八張卡仍使用原本的 data-story-control-action 與原本的 ACTIONS route，沒有事件代理複製或資料修改。
- 對話框底部「搜尋這個故事」和「全部故事工具」保留，一鍵可用。
- 故事總覽的外框、卡片、字色採夜灣現有 night/mist/rose 語義色票，不覆蓋作者自訂 HTML。

## 回歸
- 390/1280px：八個原有操作節點保留；輕鬆預設折疊，展開後可用；標準／專業預設展開。
- 晨霧背景正確、文字可讀、頁面無橫向溢出。
- 原有故事總覽開啟、故事擴充切換、故事搜尋等 E2E 維持成功。
- Core、Fast Browser E2E、Firefox、WebKit 全綠後才合併。
