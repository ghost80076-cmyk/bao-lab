# AV 異世界專用世界書

此版本將作者《世界模擬器-成人版 AV異世界》的專用設定做成可選世界書，
保留所選原文，不把專有地名、人物、魔法與勢力改寫為泛用題材摘要。

玩家入口為「世界模擬器－AV異世界（部分搬入）」，下分世界與地理、人物檔案、
魔法與道具、勢力與暗線四章。標示為作品專用，預設不啟用。

## 已交付範圍

- 原書共 251 條，其中 209 條為繼承模板，42 條為本作追加設定。
- 本版對 42 條追加設定發布 33 個召回條目，對應 27 個來源。
- 26 個來源的完整原文可由各段及原始空白重新組合，字串雜湊相同。
- 世界核心來源只保留世界與文明介紹，未發布原文的未成年性化年齡門檻。
  沒有改大人物年齡，也沒有替換原作敘述。
- 另 15 個來源未發布。涉及未成年性化內容、技能或目標的內容不轉製；
  其餘開局、NPC 生成與狀態欄協議仍待作品適配。

這不是原書全量搬運，也不是完整遊戲。書中的魔法、道具與權能是世界資料，
套用不會自行建立主線、數值結算、角色名冊或物品狀態。

## 故事行為

選取後保存四章的故事快照。切換到其他專用世界時停止啟用本書；
通用參考可繼續搭配，原有世界快照不刪除。
關鍵詞使用人物名字、地名、勢力和專有術語，避免「角色」「世界」等泛用詞。
沿用既有每輪最多四條、2200 字的召回預算與穩定前綴。

家族秘寶、人物內情、神化內情、暗潮與世界真相依各自資訊條件召回。
條件尚未成立時，普通人名和地名不會帶出深層真相。
目前使用既有「已得知資訊」控制，並未新增自動劇情解鎖引擎。
這些條件隔離的是正常故事召回；公開前端檔案仍可被取得，不能當作資料保密。

## 來源與驗證

`data/astral-worldbook-source-map.json` 記錄逐段來源索引、完整原文雜湊、
字元區間、片段雜湊、揭露條件與未發布項目，不保存未發布正文。
`world-simulator-general-source-map.json` 與 `world-simulator-layer-review.json`
保留先前通用參考庫的盤點快照；它們不再作為所有作品搬運的當前進度。

重建命令：

```sh
python3 scripts/migrate-astral-worldbook.py /path/to/source.zip
node tests/astral-worldbook-core.cjs
node tests/worldbook-library-runtime.cjs
```

轉換器鎖定已核對的來源內容集合。原檔變更會中止轉換，必須先檢查變更，
不會把未檢視的新內容直接發布。原始 ZIP 不納入公開倉庫。
