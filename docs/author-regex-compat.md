# BAO/LAB 作者正則介面｜第一階段相容測試

此功能是**獨立的介面預覽**，不是已完成的酒館／Hearthroom 全格式相容層，也不會直接取代聊天泡泡。

## 使用

1. 進入角色卡的故事，展開「作者正則介面（測試版）」。手機版可在聊天主區域找到入口。
2. 匯入原始正則 JSON，或使用「從本張角色卡來源讀取正則」（僅適用於已保留來源正則的匯入角色卡）。原始檔不會被改寫；不要拿舊版正則工具重新匯出的純文字 JSON 取代原檔。
3. 勾選「在這張角色卡啟用作者介面」。需要作者 JavaScript 的作品，只有在確認信任來源後才另行勾選「允許作者腳本」。
4. 選擇「開場畫面」或「最新 AI 回覆」，按「開啟隔離介面預覽」。若文字未匹配規則，系統不會憑空生成畫面。

## 分工與限制

- 正則在背景工作執行緒處理，有兩秒處理上限；作者的 HTML/CSS 和獲得同意的 JS 在獨立 iframe 顯示，不與 BAO/LAB 主頁共享來源權限。
- 作者腳本可呼叫 `BAOAuthor.getState()` 取得有限的展示用世界狀態；當狀態更新時收到 `bao:statechange` 事件。它**不能直接修改世界狀態**。
- 作者按鈕若呼叫 `BAOAuthor.draft('玩家的行動')`，只會把不超過 500 字的文字填入玩家輸入框；玩家仍需自己按「送出」。
- 原本依賴其他平台特定 DOM、輸入框、全域物件或 localStorage 的腳本未必相容。外部 HTTPS 圖片可以載入，也可能將已展示資料傳至圖片提供者；不要在不信任的卡片上允許腳本。
- 目前**不會**根據作者腳本重新呼叫模型、擲骰後自動送出、改寫故事原文、世界狀態或長期記憶；既有主模型、狀態模型及智慧記憶總結流程保持獨立。
- HTML/CSS/JS 與正則檔本身在玩家瀏覽器處理，不會自動送入 AI 提示詞，因此預覽不產生額外 API Token；若角色設定或 AI 回覆本身很長，原有的模型呼叫仍照常計費。
