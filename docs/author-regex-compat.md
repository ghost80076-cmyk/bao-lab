# BAO/LAB 作者正則介面｜相容測試版

這一版已增加**聊天內嵌作者介面**：正則命中最新一段 AI 回覆（或尚未開始時的開場白）後，HTML／CSS 在聊天區的隔離 iframe 顯示，不必先按預覽按鈕。原始故事文字仍保留，可按「查看原文」切換。原有獨立預覽保留作為檢查工具。這不是已完成的酒館／Hearthroom 全格式相容層。格式與顯示能力分開列於[相容對照](./author-rendering-compatibility.md)。

## 作者和玩家怎麼使用

1. 進入角色卡的故事，展開「作者正則介面（測試版）」。手機版入口在聊天區。
2. **從帶有完整來源正則的匯入角色卡開始故事時，BAO/LAB 會自動把原始規則連結到該角色的本機設定，但預設停用，並且絕不自動授權 JS。**如果作者正則是獨立檔案，也可以另外匯入原始 JSON。每張角色卡的設定分開保存；既有的玩家選擇不會被自動連結覆寫。
3. 勾選「在這張角色卡啟用作者介面」，符合規則的最新 AI 回覆會在聊天區顯示介面；點「查看原文」可回到原始劇情。只有信任來源時才另行允許作者 JavaScript。
4. 開屏、圖鑑、狀態欄所需的**觸發標記仍須出現在原始開場或回覆裡**；匯入一份正則檔本身不會生成這些資料。獨立預覽可以用來排查標記是否命中。

請保留作者原始 JSON：舊版「正則管理器」是純文字工具，重新匯出的資料不能代替原始 HTML／CSS／JS 正則。

## 介面、狀態、記憶的界線

- 正則在瀏覽器背景工作執行緒處理，單次逾兩秒即停止；作者 HTML／CSS 與經過明確同意的 JS 位於**無同源權限**的隔離 iframe。作者介面不能直接讀取 BAO/LAB 的 API Key、故事資料庫或主頁 DOM。
- 作者腳本可使用 `BAOAuthor.getState()` 和 `bao:statechange` 接收有限的展示用世界狀態；`BAOAuthor.draft('行動')` 只能填入最多 500 字的草稿，必須由玩家自行送出。
- 目前只對**最新一段匹配的回覆**提供嵌入顯示，較早訊息保留原始閱讀內容。若規則未匹配、處理超時或不相容，保留原文；不會修改聊天紀錄、世界狀態、總結或 API 路由。
- 作者的原始 HTML、CSS、JS、正則檔不加入模型提示詞；但 AI 本來需要輸出的狀態標記、世界書規則及劇情文字，仍然計入原有 Token。

## 尚未完成與已知差異

- 其他平台腳本若依賴主站 `.chat`、原平台輸入框、`localStorage`、自訂全域函式或持續駐留的整頁介面，放進隔離 iframe 後**不保證直接可用**。需要逐項做相容橋接，不應關閉沙盒來偷取完整相容性。
- 已有玩家選用的[跨回合常駐作者介面](./author-regex-dock.md)，並可另行授權保存少量介面偏好。這不是原平台完整執行環境，也不會自動保存 DOM、任意 JS 變數或第三方 localStorage。
- [世界書擴充庫](./worldbook-library-mvp-2026-10-10.md)已有關鍵字按需召回；作者 HTML／CSS／JS／正則本身不加入故事提示詞。但模型輸出的狀態標記與 UI 文字是否影響記憶／狀態整理，仍應依作品輸出及相關流程個別驗證，不能由顯示相容推論全部免 Token。
- 本機 Chromium 的兩項聊天內嵌互動測試已通過；正式對外宣稱相容前，仍須通過 Firefox／WebKit、手機、公開 Pages 與實際作者卡的逐項操作驗收。請勿把「JSON 可匯入」視為「整套畫面與按鈕相容」。
