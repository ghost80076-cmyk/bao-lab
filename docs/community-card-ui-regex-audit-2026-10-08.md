## D｜Regex 存在但實際互動／渲染有問題

本輪發現 1 件，已在同一 PR 修正：

### 詭異任務系統

開場的「點擊查看獎勵說明」使用 inline `onclick`。官方 sidecar 會以 `allowScripts=false` 自動綁定，因此畫面雖然看似可點，實際點擊不會執行。

修正：改成原生 `<details>/<summary>`，不需要 JavaScript 權限也能正常展開。

修正後待 CI / browser regression 驗證。
