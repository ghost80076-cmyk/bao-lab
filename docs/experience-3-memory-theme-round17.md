# Experience 3.0 · 第十七輪：記憶工作台主題色一致性

2026-10-15。承接已合併的 #666。

## 發現
記憶工作台已精簡到「記憶狀態／必記事項／劇情檔案」三個主入口，但面板、側欄、統計列與近期對話仍殘留夜港專用色碼；在晨霧與暮玫主題下，看起來像突然打開另一個網站。

## 變更
- 只在晨霧與暮玫覆寫記憶工作台平台 UI；夜港原本視覺不變。
- 主面板、側欄、資訊統計、狀態卡、長期筆記、摘要預覽、Canon 卡片及輸入欄位均使用已存在的主題 CSS 變數。
- 手動整理與進階區維持目前的隱藏／展開與按鈕功能；保留錯誤提示色與鍵盤焦點。
- 連帶修正故事側欄「記憶狀態」快速卡配色。
- CSS、動態 CSS 載入 JS、site-ui 及 index.html 版本同步提升，避免舊快取資產混用。

## 不變
- 故事記憶資料、必記事項讀寫、Canon、原始對話、模型分流與 Prompt Cache。
- AI 整理頻率、狀態 API、內容生成與付費計價。
- 原生工具入口及事件處理器。

## 驗證條件
- 新增 390／1280px Playwright：記憶視窗、側欄、卡片、摘要、筆記實際計算色與三主題規格一致，切主題不修改 GameState。
- 新測試納入 Fast Browser E2E 的 Story controls job。
- Core Tests、Fast Browser E2E、手機閱讀、Firefox／WebKit 皆綠後才合併正式站。
