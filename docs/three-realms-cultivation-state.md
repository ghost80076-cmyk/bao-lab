# 三界九域修煉狀態

故事內 → 世界模組管理 → 官方模組「三界修煉」→ 套用到目前故事。UI 模式可在三界修煉頁籤查看。建議三界九域故事使用這個專用模組；舊的通用「境界」模組不會自動改寫或搬移。

新故事及既有故事均須主動啟用。開啟時沒有虛構初始境界或數值；例如在故事中說明「我是下界鬥氣路線的鬥宗，鬥氣30，上限100」，待正常狀態整理便可記錄。依既有狀態整理間隔更新，非每個輸入立即更新。停用保留資料、停止送入敘事與追蹤；其他故事不繼承。

## 欄位與數值

`modules.three_realms_cultivation` 是原生故事狀態，沿用故事儲存、讀取及備份。欄位包括路線、境界、修為描述、力量種類、剩餘力量／上限、明示的修煉進度、業力程度、功德積累、瓶頸、突破結果、飛升結果、修煉狀態與變化依據。未明示的欄位省略。

修煉進度若明示百分比，範圍為 0–100；力量為有限非負數且不可高於已知上限。業力及功德原文沒有固定數值表，維持文本程度，不設數值閾值或一比一抵消。數值格式错误則整個修煉更新不套用，其他模組仍可更新。

## 來源與境界

依作者公開世界書 `b43bd078-1b19-46e8-bfc8-952660be367d` 的條目 58–61、76–82 整理狀態契約，未複製原始匯出檔或其他未選用條目。

| 路線 | 原作明定境界 |
| --- | --- |
| 下界鬥氣 | 鬥之氣 → 鬥者 → 鬥師 → 大鬥師 → 鬥靈 → 鬥王 → 鬥皇 → 鬥宗 |
| 下界靈氣 | 飛升條件明定元嬰期；完整階梯未提供，境界保留文本 |
| 中界 | 化神期 → 煉虛期 → 合體期 → 大乘期 → 渡劫期 |
| 上界 | 小神 → 中神 → 大神 → 天君 → 天帝 |
| 鬼界 | 厲鬼 → 鬼將 → 鬼王 → 鬼帝 |

只有本批正文／玩家输入中逐字可找到的 `evidence` 才可套用有變化的修煉資料。這項檢查驗證來源存在，無法替代對文字語意的判斷；是否確實成功仍由敘事模型按契約判讀。狀態附錄本身不算證據。

已知境界變化必須提供本次 `breakthrough_result="成功"` 或 `"修為倒退"`，方向須符合境界階梯；失敗不升階。批次可能包含多次已發生突破，允許相應跨階，不自動按進度升級。

鬥宗或元嬰期飛升中界落點為化神期；大乘期／渡劫期飛升上界落點為小神，必須本次 `ascension_result="成功"`。進入鬼界須 `"墮落"`；鬼界離開须 `"回歸"`。旅程中短暫降臨另一界不改變修煉路線；場景位置由原有 location 追蹤。矛盾更新保留原狀態，在修煉頁籤顯示原因。

## 實作與驗證界限

敘事從核心狀態讀取現有修煉事實與規則。獨立狀態模型和同模型 `<BAO_STATE>` 合併模式皆經相同修煉驗證器；合併模式保留一次 API 呼叫。尚未增加自動修煉收益、材料扣除、機率擲骰、數值平衡或按鈕戰鬥；這版提供持久化的敘事修煉狀態，不是固定數值 RPG 引擎。

自動測試涵蓋數值邊界、原狀態不變、突破／倒退、飛升／墮落／回歸、舊結果不能授權新突破、兩種狀態路由、故事快照還原、停用及故事隔離。手機端測試涵蓋管理器啟用、空狀態說明、中文欄位顯示、快照還原與停用保留。未使用付費真實模型作語意準確度驗證。
