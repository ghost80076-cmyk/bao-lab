# Experience 3.0 · 第十三輪：故事擴充主題對齊

2026-10-15。承接已合併部署的 #650–#661。

## 背景
「故事擴充」有世界模組、閱讀排版、文字替換、Regex、場外人格、雙向解讀、演員模式，以及各項設定的來源、適用範圍、授權與狀態。這些資訊要保留，但晨霧／暮玫切換後，標題列、卡片、來源標籤、內嵌清單和擴充設定匯入預覽仍存在固定深夜配色，導致可讀性和整站視覺不一致。

## 本輪
- 只改平台的故事擴充視窗 CSS；夜港維持既有設計，作者提供的正文 HTML 不受影響。
- 對齊視窗、卡片、標題、meta、來源與權限標籤、清單、狀態、快速開關、JSON 匯入預覽和說明文字。
- 使用 night/mist/rose 現有語義變數，保留可識別的啟用、待審、停用文字及原本的禁用狀態。
- 快速啟用、Regex 作品授權限制、世界模組儲存、匯出／匯入與 API 都沒有改動。
- 更新資產版本避免新舊 CSS 混用。

## 驗收
- 390px 手機與 1280px 桌機切換晨霧／暮玫，視窗、卡片、模組內容清單和關閉按鈕的實際計算背景色與語義 token 一致。
- 檢查世界模組管理的原有入口仍存在，切換主題不改 GameState；關閉視窗可正常返回。
- Story controls / Core / Fast Browser E2E 全綠後才合併。
