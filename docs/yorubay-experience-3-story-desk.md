# Experience 3.0 · 第十五輪：故事管理的日常入口與進階工具分層

2026-10-15；基於 main 已部署的 #664。

## 問題
故事管理首頁同時攤開「我的故事、完整故事備份、Context Pack、外部聊天歷史、Context 預覽器」。手機版把五個功能當成平行主選項，尤其是完整備份的三顆按鈕過於狹窄。許多玩家只想回到故事或儲存，不需要先理解 Context Pack。

## 改動
- 主層保留「我的故事」及「完整故事備份」兩張卡。
- 「更多故事工具」收合前情整理／續篇、外部聊天紀錄、Context 預覽。輕鬆、標準預設收合；專業預設展開；所有模式均可手動切換。
- 原本全部五張卡與所有 data-* 操作入口都在 DOM；事件處理、匯出、匯入、Context Pack 草稿、保存策略與 API Key 清理不改。
- 390px 手機主卡使用單欄版型，匯出與本機備份各有足夠觸控高度；「匯入完整故事」獨立滿寬。其他工具展開後也是單欄，不再造成按鈕擁擠。
- 晨霧、暮玫的故事管理視窗、卡片、說明與操作控制採現有語義色票；夜港保留原本外觀。
- 調整 UI JS/CSS 資產版本，避免快取混用。

## 測試
- 在 Fast Browser E2E 的 Story controls 工作流程新增兩個現有回歸：story-tools-mobile-density、context-pack-resume，確保外部歷史、備份、續寫草稿仍能開啟。
- 在 story-control-center.spec.cjs 增加 390px / 1280px、easy/pro、mist/rose、全部五張卡和狀態未變動驗證。
- 任何失敗須修正重跑；全部 10 組 CI 通過才考慮合併部署。

## 不影響
世界書、創作者角色卡、故事正文、故事記憶、模型呼叫、快取、金流與計費均未更改。
