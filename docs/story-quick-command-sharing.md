# 玩家快捷指令分享／搬移（v1，本機 JSON）

## 需求
社群對敘事視角、玩家代演、長短文等需求互相衝突；夜灣應讓玩家自由選擇、組合自己的操作習慣，而不是由平台加一條所有故事都遵守的全域規則。本次先處理**已有的「我的快捷指令」如何跨故事攜帶與分享**，不擴張成公共搜尋或帳號同步服務。

## 使用流程
1. 進入故事 →「快捷指令」→「＋ 新增我的快捷指令」→「分享／搬移我的指令」。
2. 點「匯出指令 JSON」，只輸出本故事玩家自行建立的最多 12 條快捷指令，每條只有 `label` 和 `text`。不主動附帶聊天、人物設定、作品名、API Key、記憶、帳號或作者提供的捷徑；**若玩家把金鑰或個資直接寫在快捷指令文字內，匯出仍會包含這些原文**，分享前應先檢查。
3. 另一個故事可點「匯入指令 JSON」，選擇下載到本機的 `.json`。先解析、檢查版本與字數，再顯示名稱、完整內容、可新增／重複／超出數量。
4. 玩家按「確認加入本故事」才更動 **目前故事的** `GameState.current.quickCommands`，沿用 `App.saveStory(false)`。取消、格式錯誤、內容全重複時不修改存檔。
5. 原本點快捷指令仍只是填入輸入框，玩家可再編修，**不會自動送出**。不會因此自動啟用持續敘事偏好或代演權限。

## 檔案契約
```json
{
  "schema": "yorubay-quick-command-pack",
  "version": 1,
  "commands": [
    {"label": "第三人稱", "text": "以第三人稱書寫。"},
    {"label": "慢慢推進", "text": "以自然節奏描寫場景。"}
  ]
}
```
- 僅接受原生 v1 格式與 1～12 筆純文字；名稱最多 40 字、內容最多 600 字、檔案最多 20 KB。任意 schema/version 不自動猜測或遷移。匯入時**重新產生玩家專屬 ID**，不接受外部來源或角色 ID 寫入。
- 重複內容依修整後的不區分大小寫文字去重，也會與現有內建指令和作品指令比對，滿 12 條之後不覆蓋舊資料，會顯示略過數量。
- 預覽及列表都把內容當成純文字而非 HTML、JS；檔案由玩家本機選取，沒有上傳伺服器或外部網路呼叫。

## 快取與既有功能
- 不修改 `App.buildMessages`、`App.buildSystemPrompt`、記憶引擎、狀態欄、NPC 自主或 prompt cache stable prefix。
- 不使用／不觸發額外 Provider API；只有玩家手動送出填入的文字才走原本故事對話流程。
- 作者指令仍從角色卡讀取，不會被玩家自訂指令包取代。故事的原有快捷指令保持原樣。
- JSON 分享是離線或由玩家自行傳遞；**本批不含公開雲端社群搜尋、作者指令市場、持續全域 Prompt 組合或自動同步**。如後續想做公共搜尋，需另行設計上架／審核／儲存成本。
