# 作者、玩家與 Creator MCP 功能同步

對照主站 ddfafdb1（#817）與 Creator 0.16，這次補齊 Creator 0.17 及作者編輯入口。

| 近期功能 | 作者作品欄位／入口 | 玩家入口／歸屬 | Creator |
| --- | --- | --- | --- |
| 手機互動介面 | phone_ui；創作室手機主人／聯絡人／JSON | 故事手機設定，可覆寫或關閉 | 新增 phone_ui 產生、檢查與保存 |
| 角色頭像對話 | presentation.dialogue | 故事頭像與顯示模式 | 沿用既有 dialogue |
| 文風建議 | presentation.narrative.recommended_styles | 建議不自動啟用文風包 | 沿用 recommended_styles |
| 人格四軸 | 主角核心設定／profile，其他 NPC 按需世界書 | 人物與世界書 | 更新工作流程指引，不另建四軸狀態 |
| 懸疑案件 | 私人世界書 requires；故事內建立案件 | 世界書手動揭露旗標 | 更新原生 pack gate 指引 |
| 演繹授權／單輪觀賞 | 作者可給作品敘事建議 | 今晚的故事；玩家明示授權 | 不由卡片代設玩家授權 |
| 場景投入／劇情期待 | 與作品客觀事實分開 | 今晚的故事 | 更新歸屬指引 |
| 長期指令／快捷指令分享 | 不複製進作品每輪核心 | 今晚的故事／故事快捷指令 | 不新增角色欄位 |
| 介面／回覆語言 | 作者內容保留原文 | 玩家語言設定，兩者獨立 | 不改角色 schema |
| 狀態重建／OpenAI 參數相容 | 不需重寫角色卡 | 主站執行階段 | 不新增工具 |

手機簡易欄位與進階 JSON 共用同一份資料，雙向編輯，保留原有聊天、天氣與其他資料。草稿重新載入與 JSON 匯出都使用既有 normalize/toExport 流程；停用手機時不匯出 phone_ui。文風建議保留匯入卡的其他 narrative metadata，只更新建議清單。

玩家長期指令說明補上與單輪快捷指令的差別。本輪不修改 Prompt 組裝、既有授權、快取前綴或發送順序；完整功能組合與最終 payload 的端到端審計另需逐項驗證，不能以本次欄位同步當成已完成。

驗證包含既有手機／創作室單元回歸、新增390px草稿重開／原生匯出瀏覽器案例，Creator 真實 MCP tools/list 與 tools/call、未知欄位／超限資料拒絕及 JSON／PNG／ZIP往返。
