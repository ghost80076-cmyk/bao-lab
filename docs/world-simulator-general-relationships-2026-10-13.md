# 通用世界模擬器：人物與關係批次

承接 #600 的兩包六章，本批新增「人物與關係參考」一包八章。通用目錄累計三包十四章，對應三本來源的四十二個引用；尚有六百二十個來源出現次數待處理。這不是三本完整遷移的完成報告。

## 來源到可玩內容

來源為作者指定三本中相同的人物條目（以 AV用索引 12–19 為準，其他兩本由內文雜湊比對）：

| 原型 | 保留的互動核心 | 玩家可改變的方向 |
| --- | --- | --- |
| 健談好友 | 熱情、忠誠、吐槽與牽線；幫忙和多管閒事的矛盾 | 接受幫忙、要求保密、追問消息或拒絕 |
| 知心好友 | 傾聽、細膩、實際支援；支持與不同意可以並存 | 傾訴、只要陪伴、交換意見或獨處 |
| 競爭對手 | 自信、有能力、有底線；競爭與尊重可並存 | 挑戰、協商、退出或合作 |
| 成熟導師 | 經驗、指導、考驗；往事與立場影響判斷 | 求教、質疑、協商或拒絕考驗 |
| 溫柔導師 | 實用照顧、自有生活、尊重後輩選擇 | 接受、調整需求、婉拒或互相照顧 |
| 陽光同伴 | 直率、活動邀約、真誠；善意也可能誤判 | 加入、改活動、指正或婉拒 |
| 溫柔前輩 | 細心、負責、害羞但主動；共同事務創造再見理由 | 求助、對等合作、追問或拒絕 |
| 冷淡同伴 | 以行動表達、嘴硬；希望被理解的矛盾 | 道謝、追問、保持距離或要求說清楚 |

通用版採人物互動節選。演員參考、固定外貌與身體規格、成人專屬段落、預定戀愛階段沒有複製到此包；原始檔保持原樣。原型只能補充作品已存在的人物，不能取代其姓名、身份、年齡、能力、性別或既有關係。所有條目以 scenario 標記為「可能方向，尚未發生」。感情發展以作品已有感情線為前提，不決定玩家的回應。

## 召回與成本

預設不勾選，玩家各故事自行啟用。關鍵詞限定於具體原型或較明確別名；「角色」「朋友」「前輩」「關係」等通用詞不作觸發。自動模式可用本輪玩家輸入；僅場景模式只用地點與在場 NPC；關閉模式不注入本批章節。沿用前端本地比對、排序、去重及四章／二千二百字上限；不新增檢索模型或 embedding 呼叫。

內容在本輪動態區注入，既有 system 穩定前綴保持逐字一致。字數上限不是精確 token 上限，實際 token 與費用由所選模型計算。單章內容保持精簡，原型資料也不會自動寫回世界書。

## 來源追蹤與驗證

`audit-world-simulator-general.py` 由十四個已審來源計算四十二個引用，保留舊引用的雜湊檢查，允許新增已審項目；不同來源修訂仍須重新審查。source map 只記錄索引、來源與發布內容雜湊，以及 partial-adaptation 狀態，不攜帶原始正文。

核心測試涵蓋每個關鍵詞、通用詞誤觸發、跨包隔離、模式切換、去重、字數與章數上限及來源覆蓋；整合測試涵蓋本輪動態插入與穩定前綴；桌機／手機介面測試涵蓋預設關閉、勾選與故事保存。沒有用這些確定性測試宣稱實際遊玩的召回率或跨模型敘事評測已完成。
