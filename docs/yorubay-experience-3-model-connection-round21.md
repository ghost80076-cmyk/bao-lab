# YoruBay Experience 3.0｜第二十一輪：模型連線降噪

日期：2026-10-15。

## 玩家回饋
- 右下角「投餵肉包」會在建立故事／設定流程遮住主要確認操作。
- 模型連線頁把 Model ID、拉取模型、Base URL、Protocol 與多段說明堆在一起，初次玩家很難判斷先後順序。

## 調整
- 建立故事、原生 dialog、玩家設定 modal 與故事模型 modal 開啟時隱藏浮動支持入口；支持功能不再覆蓋主要操作。
- 一般連線流程維持「模型服務 → API Key → 模型」。
- 「更多模型／從帳號取得」降級為模型欄下方的「找不到模型？」按需展開入口，預設不佔版面。
- 進階連線只保留給自訂 API、中轉與特殊服務，欄位排序統一為 Protocol → Base URL → Model ID，並改為單欄閱讀。
- Builder 的模型清單抓取失敗改成玩家可理解的簡短訊息，不再直接把瀏覽器 Load failed 類字樣當主要回饋。
- 夜灣燈火與 LM Studio 不顯示不適用的「從帳號取得模型」入口。

## 不變
API 路由、模型 preset、BYOK 金鑰處理、燈火計費、故事設定、記憶與存檔格式都不更動。

## 回歸
既有 quick-start Chromium suite 新增：390px 下浮動支持入口不遮擋、模型探索預設收起、進階欄位順序正確、頁面無橫向溢出。
