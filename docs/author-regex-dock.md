# BAO/LAB｜跨回合常駐作者介面（測試版）

這是可選的**本機顯示功能**，不是讓 AI 每輪生成完整 HTML，也不是完整的 SillyTavern／其他平台腳本執行環境。

在故事中展開「作者正則介面（測試版）」，匯入作者原始正則 JSON，或使用角色卡匯入時已保留的 `extensions.regex_scripts`。先勾選「在這張角色卡啟用作者介面」，再勾選「跨回合常駐作者介面（不必每輪重建）」。在手機上設定面板展開時可能覆蓋聊天內容，完成設定後請點面板標題收合。

## 靜態顯示、腳本與外部素材是三件不同的事

- **HTML／CSS：**正則替換中含有 JavaScript，也仍會盡可能顯示靜態畫面。未授權腳本時，作者畫面使用沒有 `allow-scripts` 的獨立 `iframe`，CSP 也設為 `script-src 'none'`；`<script>`、`onclick` 等互動不執行。這不是刪掉原始角色卡中的腳本。
- **作者 JavaScript：**只有玩家另外勾選「允許作者腳本」後才在 `sandbox="allow-scripts"`、**不含** `allow-same-origin` 的 iframe 執行。腳本不會自動得到 BAO/LAB API Key、主頁 DOM 或故事資料庫。允許作者 JS 仍有風險：腳本可能透過導覽等途徑對外傳送它取得的資訊，沙盒不是可信任來源審核的替代品。
- **外部圖片／字型／媒體：**第三個獨立開關「允許作者介面載入外部圖片／字型／媒體」預設關閉。關閉時只允許 `data:` 內嵌素材；開啟後只對 iframe 的這些資源開放 HTTPS。外部站台可能看見 IP、請求時間及網址包含的資訊。此開關**不代表授權腳本**，也不能保證已授權腳本完全無法透過其他途徑傳資料。

這些設定以角色卡為單位保存在玩家瀏覽器；重新匯入正則會重設開關，已有設定不會因一般聊天回合被覆蓋。

## 常駐介面與狀態

第一次命中有效的 HTML／CSS 正則時，會在聊天區上方建立可收合的「常駐作者介面」。之後一般對話更新或重畫聊天記錄，**不會重建已掛載的 iframe**，也不會把這份排版送給模型。按「重新選取介面」可主動從最近的 AI 回覆或開場重新尋找正則。沒有命中時保留原文，不捏造介面。逐則聊天顯示與常駐模式互斥，避免重複執行。

介面獨立於聊天紀錄與存檔：常駐區可顯示世界時間、地點、NPC 數。只有授權了作者腳本，腳本才可透過 `BAOAuthor.getState()`、`bao:statechange` 讀取限縮快照（時間、地點、最多 16 位 NPC 的有限欄位，以及最多 12 位角色的有限狀態欄）。`BAOAuthor.draft('選項')` 只能填入玩家輸入欄，必須由玩家自己送出。這個草稿橋接不是通用遊戲操作 API。

**舊平台輸入框相容（有限）：**部分原始角色卡按鈕會尋找 `.chatMsgTextarea textarea` 或 `.chat-input-scope textarea`，將選項填入輸入框。BAO/LAB 對符合特定舊版選擇器的正則，會在已授權的隔離畫面內建立假的輸入框，再把玩家操作後的文字轉交草稿接口。這不直接送出、不改寫存檔，也不讓作者腳本接觸主頁；仍不包含原平台全域函式、儲存、送出鈕或其他專屬協定。

切換故事、離開聊天、關閉常駐或停用作者介面會銷毀 iframe；重新開啟從故事資料重新渲染。**跨回合常駐不等於重新整理網頁後保留作者腳本內部變數**；尚未實作遊戲 UI 內部狀態的存檔還原，也未將作者介面加入 Google Drive 同步。

本功能不增加額外 AI 請求，也不把作者 HTML／CSS／JS／正則檔送入提示詞；**模型原本輸出的觸發標記、世界書內容和狀態整理仍照常消耗 Token**。匯入成功不等於完整相容；需以實際作品逐項驗證。公開 Pages 的瀏覽器測試也必須確認已部署的是對應提交，而非把程式提交或本機測試當成正式網站驗收。
