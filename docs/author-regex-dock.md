# BAO/LAB｜跨回合常駐作者介面（測試版）

這是可選的**本機顯示功能**，不是讓 AI 每輪生成完整 HTML，也不是完整的 SillyTavern／其他平台腳本執行環境。

在故事中展開「作者正則介面（測試版）」，匯入作者原始正則 JSON，或使用角色卡匯入時已保留的 `extensions.regex_scripts`。先勾選「在這張角色卡啟用作者介面」，再勾選「跨回合常駐作者介面（不必每輪重建）」。在手機上設定面板展開時可能覆蓋聊天內容，完成設定後請點面板標題收合。

## 靜態顯示、腳本、世界狀態與外部素材分開授權

- **HTML／CSS：**未授權腳本時仍盡可能顯示靜態畫面。介面使用沒有 `allow-scripts` 的獨立 `iframe`，CSP 設為 `script-src 'none'`；`<script>`、`onclick` 等互動不執行，原始角色卡檔案不會被改寫。
- **作者 JavaScript：**只有玩家勾選「允許作者腳本」後才在 `sandbox="allow-scripts"`、不含 `allow-same-origin` 的 iframe 執行。它不能直接讀取主頁 DOM、API Key 或故事資料庫。但已授權的作者腳本仍可能透過導覽等途徑對外傳送它取得的資訊，沙盒不是來源審核的替代品。
- **世界狀態：**另有「允許作者腳本讀取本故事的世界狀態」開關，預設關閉。只有同時允許 JavaScript 與世界狀態讀取，`BAOAuthor.getState()`／`bao:statechange` 才收到限縮快照（時間、地點、最多 16 位 NPC 的有限欄位及最多 12 位角色的有限狀態欄）。取消授權會銷毀舊 iframe，防止繼續沿用舊快照；已經被腳本讀取的資料無法追回。
- **外部圖片／字型／媒體：**獨立開關預設關閉，只允許 `data:` 素材；開啟後允許 HTTPS 圖片、字型與媒體。資源站可能得知 IP、請求時間及網址包含的資訊。開放外部素材不代表授權腳本。

上述授權以角色卡為單位保存在目前瀏覽器；新匯入正則預設全部關閉，既有設定不會因一般聊天回合被覆蓋。

## 常駐介面與跨回合狀態

第一次命中有效的 HTML／CSS 正則時，會在聊天區上方建立可收合的「常駐作者介面」。之後一般對話更新或重畫聊天記錄，不會重建已掛載的 iframe，也不會把這份排版送給模型。按「重新選取介面」可從最近的 AI 回覆或開場重新尋找正則；未命中時保留原文。逐則聊天顯示與常駐模式互斥。

`BAOAuthor.draft('選項')` 只能填入玩家輸入欄，必須由玩家自己送出，不會替玩家呼叫 API。部分舊卡會尋找 `.chatMsgTextarea textarea`，在授權腳本的隔離畫面內有有限的輸入框相容層；這仍不是完整原平台全域函式或儲存 API。

## 可選：將少量作者介面偏好存進故事

在作者正則設定另行勾選「允許常駐作者介面儲存少量顯示偏好到本故事」後，已授權的作者 JavaScript 才可以明確呼叫 `BAOAuthor.saveUIState({tab:'photos', page:2})`。只允許最多 24 個簡單欄位、總長最多 4 KB 的扁平 JSON 物件（短字串、布林、有限數字及短字串陣列），拒絕明顯的密碼／Token／Key 欄位名稱。作者程式可用 `BAOAuthor.getUIState()` 讀取已載入的偏好，並監聽 `bao:uistatechange` 更新介面；不能直接指定世界狀態、修改聊天紀錄、傳送訊息或接觸 API Key。

保存的 `authorUi` 會跟隨目前故事的自動存檔、手動存檔與完整 JSON 備份，也可在匯入該故事後還原。它**不會加入 GameState、AI 提示詞或每輪 Token**。這是作者需配合上述介面接口自行保存的偏好，並非自動保存 iframe 的所有變數、HTML 或 DOM。請勿在作者介面填入密碼或金鑰；名稱及容量檢查不能保證內容本身沒有敏感資料。取消存檔授權會阻止後續讀寫，但不會自動刪掉先前故事備份中的資料。Google Drive 是否同步取決於所用的故事備份／同步流程，未另外驗證。

切換故事、離開聊天、停用常駐或授權變動時會銷毀 iframe；重新開啟會從故事來源重建畫面，再送出已保存的偏好。並非完全相容任意第三方卡；必須用實際作品逐項驗證。

本功能不增加額外 AI 請求，也不把作者 HTML／CSS／JS／正則檔送入提示詞；**模型原本輸出的觸發標記、世界書內容和狀態整理仍照常消耗 Token**。公開 Pages 驗收必須確認部署的是對應提交，不能把提交或本機測試當成正式網站驗收。
