# BAO/LAB｜跨回合常駐作者介面（測試版）

這是可選的**本機顯示功能**，不是讓 AI 每輪生成完整 HTML，也不是完整的 SillyTavern／其他平台腳本執行環境。

在故事中展開「作者正則介面（測試版）」，匯入作者原始正則 JSON，或使用角色卡匯入時已保留的 `extensions.regex_scripts`。先勾選「在這張角色卡啟用作者介面」，再勾選「跨回合常駐作者介面（不必每輪重建）」。對來源完全信任、且需要互動腳本時，才另外允許 JavaScript；**預設不執行作者腳本**。

第一次命中有效的 HTML／CSS 正則時，會在聊天區上方建立可收合的「常駐作者介面」。接下來一般對話更新或重畫聊天記錄，**不會重建已掛載的 iframe**，也不會把這份排版送給模型。按「重新選取介面」可主動從最近的 AI 回覆或開場重新尋找正則。沒有命中時保留原文，不捏造介面。一般逐則聊天顯示與常駐模式互斥，避免重複執行。

介面獨立於聊天紀錄與存檔：它只從目前故事的 `GameState.current` 接收限縮的展示快照（時間、地點、最多 16 位 NPC 的名稱／心情／位置／在場資訊，以及最多 12 位角色的有限狀態欄）。沒有開啟作者腳本時，常駐區仍顯示原生的時間／地點／NPC 數；已明確授權的腳本才可透過 `BAOAuthor.getState()`、`bao:statechange` 讀取快照。`BAOAuthor.draft('選項')` 只能填入玩家輸入欄，必須由玩家自己送出。作者 iframe 不具有主頁同源權限，不能讀取主頁 API Key、主頁 DOM 或故事資料庫。允許腳本仍有風險：作者內容可利用外部圖片連結傳出**展示快照**，請勿授權不信任的來源。

切換故事、離開聊天、關閉常駐或停用作者介面會銷毀原有 iframe；重新開啟會由原始故事資料重新渲染。**跨回合常駐不等於重新整理網頁後保留作者腳本內部變數**；尚未實作遊戲 UI 內部狀態的存檔還原，也未將作者介面加入 Google Drive 同步。原本的故事、記憶和世界狀態儲存流程不變。

本功能不增加額外 AI 請求，也不把作者 HTML／CSS／JS／正則檔送入提示詞；**模型原本輸出的觸發標記、世界書內容和狀態整理仍照常消耗 Token**。其他平台依賴原站全域函式、DOM、localStorage 或專屬互動協定的作品，仍須逐項建立相容橋接；請先用實際作品驗收，不要將「正則 JSON 成功匯入」等同「完整相容」。
