# BAO/LAB｜跨回合常駐作者介面（測試版）

這是可選的**本機顯示功能**，不是讓 AI 每輪生成完整 HTML，也不是完整的 SillyTavern／其他平台腳本執行環境。

在故事中展開「作者正則介面（測試版）」，匯入作者原始正則 JSON，或使用角色卡匯入時已保留的 `extensions.regex_scripts`。先勾選「在這張角色卡啟用作者介面」，再勾選「跨回合常駐作者介面（不必每輪重建）」。在手機上設定面板展開時可能覆蓋聊天內容，完成設定後請點面板標題收合。

## 畫面、腳本、世界狀態與外部素材分開授權

- **HTML／CSS：**正則替換中含 JavaScript，也仍會盡可能顯示靜態畫面。未授權腳本時，使用沒有 `allow-scripts` 的獨立 `iframe`，CSP 設為 `script-src 'none'`；`<script>`、`onclick` 等互動不執行，原始角色卡不會被刪改。
- **作者 JavaScript：**只有玩家勾選「允許作者腳本」後才在 `sandbox="allow-scripts"`、**不含** `allow-same-origin` 的 iframe 執行。作者腳本無法直接讀取 BAO/LAB 主頁 DOM、API Key 或主頁儲存空間；仍可能藉由自身 iframe 導覽等途徑對外傳送**它已取得的資訊**。單純勾選 JS 不再提供世界狀態。
- **世界狀態資料：**另一個獨立開關「允許作者腳本讀取本故事的世界狀態」，預設關閉；**必須同時授權作者 JS 與世界狀態**，作者程式才能經 `BAOAuthor.getState()` 和 `bao:statechange` 收到時間、地點、有限的 NPC 與人物狀態欄。只開 JS 時，`getState()` 保持空物件，作者按鈕仍可填入草稿。關閉狀態授權會重新建立介面，以清掉該介面內既有的快照，但**無法追回作者程式先前已讀取或傳出的資料**。常駐區外層 BAO/LAB 原生時間／地點文字不受此開關影響。
- **外部圖片／字型／媒體：**獨立開關「允許作者介面載入外部圖片／字型／媒體」預設關閉。關閉時素材只允許 `data:` 內嵌資源；開啟後對這些資源開放 HTTPS。資源供應方可能看到 IP、請求時間與網址資訊。即使不開外部素材，**已授權的 JS 仍不保證無法經其他途徑對外傳資料**。

權限以角色卡為單位保存在玩家瀏覽器；重新匯入正則會重設開關。這些開關與故事內容、API 金鑰、Token 用量彼此分離。

## 常駐介面與操作

第一次命中有效的 HTML／CSS 正則時，會在聊天區上方建立可收合的「常駐作者介面」。之後一般對話更新或重畫聊天記錄，**不會重建已掛載的 iframe**，也不會把這份排版送給模型。按「重新選取介面」可主動從最近的 AI 回覆或開場重新尋找正則。沒有命中時保留原文，不捏造介面。逐則聊天顯示與常駐模式互斥，避免重複執行。更改權限時會重建 iframe，與一般跨回合更新不同。

`BAOAuthor.draft('選項')` 只會填入玩家輸入欄，必須由玩家自己送出；它不是通用的遊戲操作 API。**舊平台輸入框相容（有限）：**部分原始角色卡按鈕會尋找 `.chatMsgTextarea textarea` 或 `.chat-input-scope textarea`；BAO/LAB 可在授權的隔離畫面內建立假的輸入框，把玩家操作後的文字轉交草稿接口。這不直接送出、不改寫存檔，也不讓作者程式接觸主頁。原平台的全域函式、儲存、送出鈕或其他專屬協定仍未完整支援。

切換故事、離開聊天、關閉常駐或停用作者介面會銷毀 iframe；重新開啟從故事資料重新渲染。**跨回合常駐不等於重新整理網頁後保留作者腳本內部變數**；尚未實作遊戲 UI 內部狀態的存檔還原，也未將作者介面加入 Google Drive 同步。

本功能不增加額外 AI 請求，也不把作者 HTML／CSS／JS／正則檔送入提示詞；**模型原本輸出的觸發標記、世界書內容和狀態整理仍照常消耗 Token**。匯入成功不等於完整相容；需以實際作品逐項驗證。公開 Pages 的瀏覽器測試也必須確認已部署的是對應提交，而非把程式提交或本機測試當成正式網站驗收。
