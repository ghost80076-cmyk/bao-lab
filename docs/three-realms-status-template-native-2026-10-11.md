# 三界九域：可選人物狀態範本

第 16 批依來源 172 新增「三界人物狀態」快速範本，位於既有狀態欄管理器。六個文字欄位是身體狀態、精神狀態、關係階段、好感描述、目前行動、關鍵轉折。只有玩家選擇範本並套用後才寫入本故事；開新故事及原角色卡維持原有欄位。

所有欄位預設「未確認」，不用 0、正常或陌生冒充已知狀態。好感可使用低／中／高／極高描述，不把既有數字自動換算成未知閾值；關係與心理只依已確認互動及表達更新。離場推測不作為當前行動，轉折只整理一至兩條已發生事件。這個範本不新增修煉能量計算、成人額外數值或自動離場導演。

範本透過既有 character status 自訂欄位管線加入，重複選擇不會重複加欄；既有作者／玩家欄位保留。存檔、讀取、攜出與刪除沿用原管理器。追蹤是否使用同模型合併或既有狀態請求，依故事原有設定；本批沒有獨立追蹤器或新增第三套狀態資料。

`three-realms-status-provenance.json` 記錄作者公開來源 172 的指紋、範本 ID、六個欄位與適配範圍。逐條進度更新為 `native_status_template`，保留作品呈現評測 follow-up；其餘 factual 及原生提示計數不變。

本地人物狀態、同模型合併、前端載入契約套件通過；手機 E2E 新增未選用、草稿不改狀態、重複選擇、未知預設、套用、存檔、讀取與手機寬度檢查。實際瀏覽器結果以本批 CI 為準。
