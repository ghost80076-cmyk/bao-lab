# 作者初始 NPC 編輯器 P0（2026-11-06）

## 範圍
「角色卡創作室 → 人物與世界」既有進階區加入選用的初始 NPC 編輯器。
直接操作現有 initial_state.npcs；不建立另一份 NPC 資料庫、不改世界模組／記憶／狀態／供應商請求。

- 可新增、讀取、修改及移除 NPC；姓名／別名衝突時拒絕，已建 NPC 不在此直接更名，避免破壞其他以角色名索引的資料。
- 外貌、穿著、人格、當前情緒、位置、在場狀態及單向關係都映射現有原生 NPC 欄位。
- 角色目標寫入原生 notes 的專用可逆段落，仍會按原有 NPC Prompt 行為提供給模型。原本的 notes 其他文字保留；異常／重複標記拒絕覆蓋。
- 作者秘密備註寫入現有 creator_notes 中的姓名標記段落，預設不給模型，但只表示作者資料：匯出卡片仍可讀取，不能拿來保管真正的私密資料，啟用 include_creator_notes 時可能進模型。
- 刪除 NPC 僅清除其初始名冊資料與此工具的作者備註，不自動刪除既有世界書、角色頭像、初始狀態欄或故事存檔。
- 未按「儲存這位 NPC」的表單不會被當成卡片資料；主草稿儲存／匯出前會阻止遺漏未提交的編輯。
- 全部操作只改當前瀏覽器草稿，仍需作者使用原本的「儲存草稿／匯出 JSON／加入我的角色」。不會觸發模型、計費或公開上架。

## 回歸驗收
- 核心：node tests/character-studio-npc-editor-core.cjs
- 瀏覽器：tests/e2e/character-studio-npc-editor.spec.cjs（390/1280 寬度）；含原生 JSON 往返、編輯保留其他欄位、拒絕未提交的儲存、草稿重載。
- 保留現有角色卡 schema 1.5 / Creator MCP 的輸出契約。
- CI 與正式站的部署驗證獨立；無付費實際模型、真機鍵盤測試。
