# Experience 3.0 — 工具選單資訊架構重整（第 22 輪）

日期：2026-10-15

## 玩家反饋
- 「我的人物」不應散落於其他工具；玩家會在「人物與世界」尋找它。
- 「長期指令」藏在「敘事與描寫」末段，找不到預期入口。
- 桌面側欄、全部工具抽屜、手機工具與故事總覽的分類不一致。

## 統一分類

| 分組 | 功能定位 |
|---|---|
| 人物與世界 | 我的角色／加入 NPC、人物狀態、世界書、世界資料 |
| 故事與記憶 | 故事、存檔、分支、記憶、匯入匯出 |
| AI 與指令 | 模型連線、回覆設定、敘事偏好、長期指令 |
| 畫面與操作 | 聊天外觀、場景顯示、狀態面板 |
| 其他與支援 | 離開故事、贊助入口與次要操作 |

- 同一組分類在桌面側欄和「全部故事工具」依一致順序顯示；手機沿用相同抽屜分類。
- 拆開原本混在設定容器內的記憶與聊天外觀按鈕，保留原生事件、資料與 API。
- 「我的人物」使用原本的 `#bao-actor-entry`，不另建第二套人物庫。
- 「長期指令」直接開啟既有敘事設定中的 `#bao-narrative-instructions` 區，定位與聚焦；仍使用同一儲存流程，既有敘事入口完整保留。
- 故事總覽的次要工具區增加直達長期指令卡，不提高初始常用四卡密度。
- 工具搜尋支援長期指令／自訂指令／prompt／提示詞、我的人物／NPC／玩家角色等別名。

## 驗收
- Desktop 1280px / Mobile 390px：分類順序一致、無橫向溢出。
- 人物庫、記憶、外觀及長期指令各只有一份來源操作處理。
- 搜尋 prompt 能顯示「長期指令」，且可直接開啟、聚焦、儲存再重新讀取。
- 故事總覽能開啟同一指令編輯區。
- 不觸及 prompt 規則、安全策略、模型路由、計費與本地存檔架構。
