# 白燼｜廢城裡的同行者

依作者本輪對話與指定附件整理，作者為「班長」。封面採作者選定的黑裙、白髮紅瞳、陶瓷杯版本，保留完整9:16構圖並轉為WebP。

## 保留的創作骨架

- 20歲白燼：白髮紅瞳、強大戰力、紅色十字吊墜與千化刃。
- 自主生活與人物矛盾：接受照顧、掌握選擇、維持關係之間的拉扯。
- 生存、共同生活、交易、曝光勢力與E-00長線依因果交錯；五位周邊人物各有目的。
- 隱性關係因素分別變化，不以百分比與固定階段攻略角色。
- 開場是廢城公寓的熱水、地圖與灰市行程，留下確認聲響、討論路線、接住玩笑三種介入方向。

## 夜灣適配

LUNA的重複全局與逐輪文字狀態欄交由夜灣原有機制承接。角色特有的行動、事件與關係邏輯保存在角色提示和三條情境世界書中。

原生UI提供「此刻」「生存」「線索與關係」三面板。已知消息使用「她稱」保留來源，未清點資源保持未確認。隱性關係、千化刃負荷與未公開身世放在visibility: internal的private模組；公開面板不引用這些路徑。internal為顯示隔離，並非本機檔案加密。

原生開場使用無標記正文與三條草稿按鈕，按鈕只填入文字。作者Regex僅按需排版轉場題字與玩家已讀的紙條；不替換整段開場、不執行腳本、不發出網路請求、不改寫狀態。捕獲文字由現有引擎轉義。

## 驗證

YoruBay Creator已產生1.5草稿，並驗證角色可匯入（issues=[]）及三條世界書有效。依主站現有契約將world_modules、gameplay_ui放入gameplay.world_modules、gameplay.ui_schema，補入作者、原生opening及internal visibility。

tests/bai-jin-card.cjs檢查主站正規化、公開UI路徑、內部狀態隔離、開場草稿、Regex文字保留與惡意HTML轉義。tests/e2e/bai-jin.spec.cjs覆蓋桌面與390px手機的開場、草稿不送出、狀態更新、秘密不顯示、Regex及文字模式。

本機Chromium桌面1440px與手機390px分開執行，均通過全部功能斷言；已加入CI故事體驗組。桌面與手機截圖檢查後，將位置卡改成緊湊文字資訊，避免把人物封面當橫向場景圖而裁掉面部。本機缺中文系統字型，截圖只能驗證佈局，中文字型視覺需在具備中文字型的環境確認。未執行付費模型對話模擬。
