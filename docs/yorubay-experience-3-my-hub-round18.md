# YoruBay Experience 3.0｜第十八輪：我的頁面主次工具分層

日期：2026-10-15。

## 問題
「我的」頁面原本把故事、人物、內容顯示、跨裝置、角色實驗室與作品說明六張卡同級排列。新玩家會先被較少使用的入口淹沒，而不是直接找到故事和人物。

## 修改
- 帳號與燈火保留現有入口。
- 我的故事、我的人物、內容顯示保留最上層與原始事件處理。
- 跨裝置、角色實驗室、作品與說明放入單一「更多設定與工具」`details`，點一下即可展開。
- 輕鬆／標準預設收合，專業預設展開；玩家手動展開／收合後不因切換模式而被強制重設。
- 手機使用單欄，桌機主卡兩欄及進階卡三欄。新入口的背景、文字、焦點使用三主題語義色票。
- CSS/JS 資產版本更新，避免混用快取。

## 不變
- 所有原有 `data-bao-player-action`、`href`、內容偏好和人物入口，以及其 handler 原封不動。
- 成人內容偏好、故事、人物／關係、存檔、Google Drive、API Key、模型 API、記憶、快取、點數與費用都不改。
- 收合只是 UI 顯示，不改故事權限，不移除功能，也不改敘事渲染。

## 回歸
- 新增 390 / 1280px Playwright，覆蓋主入口可見、進階展開、專業預設展開、手動選擇保存、主題切換、對應原有入口、無橫向溢出、GameState 不變。
- 納入 Fast E2E cards-simulators 群組。
- CI 全綠、PR 無衝突後才可合併部署。
