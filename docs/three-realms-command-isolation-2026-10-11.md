# 三界指令：程式碼與輪次隔離

第 17 批加固既有 23 種原生指令，不新增來源或提示內容。

指令解析器依 Markdown fence 邊界逐行處理，支援反引號、波浪線、三個以上的長 fence、未關閉 fence 與四空格／tab 縮排程式碼。區塊裡的事件、查詢與舊世界設計指令均不執行；區塊結束後的獨立有效標記仍可使用。

訊息組裝器非同步等待後，同時核對原故事與最新玩家訊息的物件、文字；如果同故事已有更新的玩家輸入或編輯，舊指令不會注入新一輪訊息。原有停用、切故事與單輪隔離仍保留。

核心回歸涵蓋短／長／波浪／未閉合／縮排 fence、關閉後指令與正常標記；VM 回歸涵蓋等待中新增輸入、切故事、讀取與零額外請求。手機 E2E 增加程式碼範例不觸發提示的檢查，實際結果以 CI 為準。
