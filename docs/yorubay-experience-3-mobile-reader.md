# Experience 3.0 · 第六輪：手機閱讀與輸入區配色一致性

2026-10-15。承接已部署的 PR #650–#654。

## 問題
晨霧和暮玫已能切換故事閱讀面板，但手機專屬樣式仍把頁頂、輸入區、輸入框與 AI 靈感按鈕寫成固定深黑、冷紫或白邊，導致日間主題特別突兀。這是 CSS 層問題，不是故事引擎或模型輸出問題。

## 本批修正
- 僅對晨霧、暮玫生效：手機閱讀主體、工具列、輸入框、＋ 工具、AI 靈感、對話頁頂、人物面板關閉鈕使用已定義的語義主題色。
- 工具抽屜邊界、拖拉提示與快捷入口統一主題文字和邊界對比。
- 原有夜港呈現不動，手機鍵盤／自動長高／沉浸式閱讀布局不變。
- 作者自訂 HTML 和角色卡插入內容完全不選入 CSS 修改範圍。

## 回歸門檻
- 手機 390 px 開始故事、輸入草稿後切換晨霧／暮玫，所有固定畫面元件的計算色彩符合已存在的主題 tokens。
- AI 敘事文字可讀、草稿不消失、故事內容不改變。
- 沒有橫向溢出，＋ 工具及搜尋功能依然正常。
- Core、Fast Browser E2E、手機閱讀及跨瀏覽器檢查全部通過才合併。
