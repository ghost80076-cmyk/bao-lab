# 夜灣角色匯入與作者介面相容對照

2026-10-24 依目前程式與測試整理。這是能力範圍，不是所有第三方作品的相容認證；匯入資料、渲染畫面、執行互動必須分別驗證。

## 資料格式

| 來源 | 現有入口與能力 | 限制 |
| --- | --- | --- |
| 夜灣原生 JSON | 角色匯入驗證 schema 與必要欄位，存入本機角色庫 | 以檔案實際欄位與支援版本為準 |
| 夜灣 V2 相容 JSON／PNG | 偵測 `data.extensions.yorubay.character`，優先還原完整夜灣欄位 | 不代表一般第三方 V2 卡具有夜灣擴充欄位 |
| 夜灣 `.yorubay.zip` | 匯入作品包及其圖片、正則與世界書等附帶資料 | 有包內圖片引用時需使用完整作品包，不能只取角色 JSON |
| SillyTavern V2 JSON／原始 PNG | 先顯示轉換預覽，轉換名稱、開場、人格／情境、範例對話及世界書文字；來源資料保留於匯入 metadata，PNG 可作本機封面 | 不等於執行酒館全部 extensions、原 system_prompt 或原平台腳本；一般世界書文字轉換也不等於保留全部召回語意 |
| SillyTavern V3 | 一般 V3 卡目前提示改用 V2 | 不是通用 V3 匯入器 |
| LunaTalk 世界書 `entries` | 由世界書擴充庫匯入；依關鍵字、分類與審核標記轉換 | 規則／自訂類及缺少關鍵字等條目可能需審核，不等於整張 LunaTalk 角色卡直入 |
| MMD／LunaTalk／其他平台完整角色及頁面 | 可將設定整理成夜灣原生角色與獨立正則後逐項驗證 | 沒有整套平台 DOM、全域函式或腳本環境的直接相容保證 |

## 顯示與互動能力

| 能力 | 現有行為 | 作者需驗證 |
| --- | --- | --- |
| Regex | 接受原始規則陣列、`regex_scripts`／`rules` 等支援格式；卡片來源正則可連結本機設定 | 規則欄位、觸發文字、順序與大小／逾時限制；連結不代表自動啟用 |
| HTML／CSS | 開場／最新 AI 回覆可經正則在隔離 iframe 顯示；保留查看原文 | 原平台 CSS、相對素材路徑及手機排版 |
| 作者 JS／外部素材 | 分開取得玩家授權；JS 執行於無同源權限的 iframe | 原平台專用全域函式、儲存 API、父頁 DOM 不保證可用 |
| 常駐 HUD／圖鑑／手機介面 | 玩家可啟用跨回合常駐模式，避免一般回覆時重建；與逐則嵌入模式互斥 | 故事切換、離場及權限變動會銷毀／重建 iframe，不是完整應用快照 |
| 世界狀態 | 另行授權後透過 `BAOAuthor.getState()`／`bao:statechange` 讀有限快照 | 不得假設有完整人物、聊天歷史或可任意寫入世界狀態 |
| 按鈕 | `BAOAuthor.draft(text)` 填入草稿，由玩家送出 | 不會自動呼叫模型；已有草稿可能要求確認覆蓋 |
| 介面偏好 | 常駐＋JS＋存檔授權後可用 `getUIState`／`saveUIState`；隨故事備份還原 | 最多 24 個簡單欄位、4 KB；不自動保存整個 DOM 或任意 JS 變數 |
| 多開場 | 酒館轉換優先使用 `first_mes`，空缺時取第一個 `alternate_greetings`；完整來源另保留 | 不代表提供酒館全部候選開場的原樣選擇器 |

## Token、快取與驗收

- 本機正則轉換、iframe、按鈕填草稿與介面偏好保存不增加模型呼叫；作者 HTML／CSS／JS／正則檔本身不加入模型提示詞。
- 模型產生的敘事、觸發標記與狀態資料仍有原本 Token 成本。世界書召回是獨立功能，不因套用作者介面而自動免費。
- 此文件更新不改 Prompt。宣稱某張卡可用前，應實測開場命中、靜態／授權 JS、桌機／手機、按鈕、跨回合、切故事及存檔還原；註明實測瀏覽器與部署版本。
