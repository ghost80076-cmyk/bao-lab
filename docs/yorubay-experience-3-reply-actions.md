# Experience 3.0 · 第七輪：每則 AI 訊息的操作列降噪

2026-10-15，承接正式部署的 #650–#655。

## 問題
AI 回覆下方在手機會出現編輯、改寫、重生成、複製、分支、回退等多個橫排操作。閱讀時視覺密度高，部分操作被擠到畫面外。

## 本輪
- 手機普通模式：保留可用的「編輯」、「重生成」及「複製」，其他操作放到原生 details「更多」。
- 舊訊息的編輯與重生成若本來就不被允許，仍保留原本停用狀態，但放入「更多」中，避免首頁露出大量不可點選操作。
- 專業模式的「更多」預設展開，玩家亦能手動開合。切換操作層級時立即更新。
- 保留既有按鈕節點與 onclick / disabled 狀態，不建立新代理事件、不改寫故事內容，不拆分作者 HTML。
- 回到桌機時恢復原有的攤平操作列；新增訊息與分支操作會按既有渲染後同步。

## 驗收
- 320/390px 不出現大量重複工具，常用操作一鍵可達。
- 展開「更多」可看到並操作 AI 改寫、分支與回退；保留停用及權限規則。
- 專業模式預設展開，改回輕鬆模式收合；桌機回復完整工具列。
- 原始訊息、分支記錄、快取和 API 功能都不修改。
- Core／手機閱讀／故事控制／跨瀏覽器 E2E 全過後才進入合併。
