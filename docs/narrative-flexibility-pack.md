# 敘事靈活性｜選配敘事強化包（2026-11-08）

## 目的與範圍

在「今晚的故事 → 沿途風景」新增「敘事靈活性」選項，key 為 `flexibility`，預設關閉。沿用既有 `narrative.storyExtras` 的正規化、勾選介面、故事偏好保存、狀態摘要與穩定 system Prompt 組裝；不新增資料 schema、API 呼叫或每輪流程。

此選項專門降低固定句式、慣性情緒描寫與機械輪替的個人小動作，讓語句、行為和敘事焦點依人物及情境變化。不新增新的 NPC 自治引擎，不改動世界模擬、角色設定、`motivation` 人物心理深度、`realist_subtext` 寫實留白、玩家主權或資訊隔離的原有權責。

## 文案邊界

- **語言與行為變化**：允許角色保留辨識度，但避免每輪必定重複某個表情、語氣、眼神或小動作。例子只能啟發，不能被當成輪替清單。
- **心理表現**：同一情緒可以有不同外顯方式；仍遵循故事原有 `innerThoughts`（不揭露／克制／明確）及敘事視角，不強制只用微表情，也不強制揭露內心。
- **自然互動**：沉默、繼續手邊事務、語句未完或無顯著表情，都可以是自然反應。不以每輪新增事件或衝突來「提高靈活性」。
- **事實與權限**：人物核心、知情邊界、已確認事件、玩家演繹授權和結構化狀態仍以既有平台／故事規則為準。
- **模型溫度**：這是文風／演繹提示，不是 Gemini、Claude 或其他 API 的採樣 Temperature 控制。模型是否改善需要獨立實聊驗證。

## 開關與相容

- 預設與舊故事無此勾選時不送出新增文案；只有手動選取才增加一小段 Prompt。
- 與 `motivation` 可同時啟用：前者控制表現變化，後者保持動機持續、策略與心理矛盾。
- 與 `innerThoughts=none` 或 `clear` 可並用，不覆蓋原設定。
- `storyExtras` 既有白名單會移除未知 key、去除重複、維持保存順序，故不需遷移。
- 本選項不涉及新 UI 類型、額外欄位、LLM 路由、計價、故事狀態、世界書、MOD 或實際 API 生成參數。

## 驗證

主要離線測試：

```bash
node tests/narrative-settings-core.cjs
node tests/narrative-prompt-pipeline-core.cjs
```

覆蓋：預設無額外 Prompt、重複選項去重、與 `motivation` 組合、內心描寫模式相容、角色控制授權不變、Gemini 與 Claude 訊息組裝、同一故事設定維持前綴位元組穩定、取消後不殘留本包文案。

此類離線驗證只確認**提示詞組裝與設定契約**，不能證明模型文筆實際改善。建議後續在相同故事、上下文、參數與模型版本下進行多次盲評，分別檢查：模板動作重複率、角色語言辨識度、非必要新事件、心理揭露是否符合設定、玩家主權與場景因果。

## 回退

移除 `extras.flexibility` 和其文件、測試即可。舊檔中存有未知 `flexibility` 值時，既有正規化流程會自動忽略，不需要故事資料遷移。
