# Creator 搬運完整性：主站相容層

Creator 0.13 使用既有 `gameplay.initial_state.worldbookLibrary` 攜帶大型世界書。單卷512筆，超過時分卷；保留原始來源、停用條目與正則資料。此主站修正必須先於 Creator 0.13 部署。

- PNG 的1MB內嵌資料上限統一以解碼後的UTF-8 JSON計算；base64傳輸膨脹不再誤判。PNG整體維持10MB，直接JSON維持1MB，均再次檢查實際資料大小。
- 原生世界書保留 `enabled: false`，召回時不選取停用條目。舊包未宣告enabled時維持原行為。
- 長條目保留完整原文；超出本輪預算時擷取與命中關鍵字相鄰的段落，標記節錄。維持本輪2200字／4條的既有預算，來源存檔不被截斷。
- 主站與後台載入相容層的新版本；新增PNG容量邊界及世界書原文／停用測試，並將PNG往返測試接入Core CI。
- Chromium在桌機及390px檢查帶100筆世界書、停用條目與來源Regex的PNG匯入、重新載入、建立狀態及提示詞隔離。

本輪不新增ZIP/CHARX作品包、不下載原作多圖片、不重寫角色與劇本、不啟用原作JavaScript，也不宣稱所有酒館進階觸發條件或UI都已相容。圖片引用與原始正則由Creator保留，後續再處理完整資產綁定。
