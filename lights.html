夜灣燈火

夜灣提供的 AI 模型服務使用額度。自己的 API，自己掌燈；需要時，也可以使用夜灣提供的一盞燈。

台灣線上付款功能準備中
燈火不是斗內，也不是可提領或交易的虛擬貨幣。
購買後會加入對應的夜灣帳號，只在使用夜灣提供的 AI 模型服務時消耗；使用自己的 API Key 不會消耗燈火。

台灣燈火方案

以下方案均以新台幣計價。正式付款入口會在台灣金流串接與審核完成後開放。

5,000 燈火NT$250
10,000 燈火NT$500
20,000 燈火NT$1,000
50,000 燈火NT$2,500

目前付款功能尚在準備。付款入口上線後，請以實際付款頁顯示的方案、金額與交易結果為準。

怎麼交付

燈火是數位服務使用額度。付款完成並確認交易後，對應額度會加入購買者的夜灣帳號。正式金流自動入帳功能上線前，如有購買需求，請先透過官方聯絡管道確認。

為避免入錯帳，購買時可能需要登入夜灣帳號或提供公開玩家編號。

燈火怎麼使用

使用夜灣提供的模型服務時，燈火會依模型、輸入與輸出用量、快取與第三方實際成本等因素消耗。使用自己的 API Key 或本地模型，不會消耗夜灣燈火。

詳細的失敗請求、結算與退款原則，請查看 燈火與退款政策。
