# 夜灣 Creator MCP｜連接、指令與跨平台搬運

教學網址：https://yorubay.com/mcp-guide
官方遠端 MCP：https://yorubay-creator-mcp.ghost80076.workers.dev/mcp
連線方式：Streamable HTTP；驗證：不需要（No authentication）。

## 1. 怎麼連接
在支援遠端 MCP 的 AI 客戶端，使用該平台提供的「新增 MCP 伺服器／連接器」入口，名稱填 YoruBay Creator，Server URL 貼上官方遠端 MCP 網址。不同平台的方案、入口與權限不同，以該平台當前提供的功能為準。連接後在對話啟用這個工具，先用下方「確認連線」指令檢查。

MCP 網址供 AI 工具連接，不是玩家上傳作品的網頁，也不會自動安裝到所有 AI 網站。支援遠端連線時不必下載或自行架設伺服器。下載的 JSON 是設定範例，僅適用於接受相同格式的客戶端；一般玩家直接填連線網址即可。


### ChatGPT 網頁／Work 連接範例

開啟 https://chatgpt.com/plugins →「＋」→ Add custom MCP server → 名稱 YoruBay Creator → 貼上本教學 MCP 網址 → 驗證選 No authentication → 確認後建立並安裝。開新對話，輸入 @ 選擇 YoruBay Creator，再貼指令。帳號或工作區若未提供這個入口，以其可用功能為準。

官方步驟：https://developers.openai.com/plugins/deploy/connect-chatgpt

## 2. 選你的情境
- 已有檔案：把原始 JSON／PNG、世界書或 CHARX／夜灣 ZIP 交給 AI，使用「從檔案搬進夜灣」。
- 同一個 AI 能連兩個 MCP：同時啟用來源平台與 YoruBay Creator，由 AI 依序讀取、整理、轉換。
- 兩個 MCP 分屬不同網站：先在來源網站匯出檔案，再下載到自己裝置，交給能連接夜灣 MCP 的 AI。兩個網站的對話不會自動互通。

MCP 是工具；負責理解作品、呼叫工具及串接流程的是 AI 客戶端。來源 MCP 不會自行呼叫夜灣 MCP，夜灣 MCP 也不會替你登入其他平台或讀取未提供的私有作品。

## 3. 可直接複製的指令
### 確認連線

請檢查目前是否已連接 YoruBay Creator MCP，列出實際可用的工具。確認是否能使用 prepare_yorubay_package。不要只依記憶回答；未連接或工具未更新就直接告訴我。

### 從檔案搬進夜灣

這是我提供的角色卡／世界書／作品包。請使用 YoruBay Creator MCP 協助搬到夜灣。先清點角色、開場、世界書總條目與停用條目、Regex、介面規則及圖片附件，再轉換。保留原作題材、角色關係、文風、規則與原文，不要自行刪減設定。依作品需求整理角色核心、劇本、配套世界書及 UI；不要把所有世界書硬塞進開場。圖片、場景、立繪與正則一起檢查；不相容的腳本、缺圖與未對應條件逐項列出。完成後驗證，使用 prepare_yorubay_package 交付可匯入夜灣的 .yorubay.zip；如果只有純設定才使用 JSON，單封面角色卡可用 PNG。請交付實際檔案資源，不要假裝已上架或編造下載網址。

### 同一個 AI 同時使用兩個 MCP

我已連接來源平台的 MCP，以及 YoruBay Creator MCP。我要搬運的作品是：【填作品名稱或 ID】。
先用來源平台 MCP 唯讀取得我有權讀取的作品資料；包含角色設定、所有開場與範例、世界書完整條目（含停用項）、Regex、介面設定與圖片清單。不要修改、刪除或發布來源作品。遇到分頁要讀完；工具無法提供的項目標明缺漏，不得宣稱已完整取得。
接著由你整理交接資料，保留原始欄位、條目 ID、順序、觸發條件、圖片原始檔名／引用與來源關係，交給 YoruBay Creator MCP 遷移。不要擅自改題材、角色關係、玩法或文風。可以優化夜灣的欄位配置、狀態、原生 UI 與 Regex 顯示，但列出適配改動。
最後核對來源與輸出的條目／圖片數，驗證夜灣格式並用 prepare_yorubay_package 交付 .yorubay.zip。原圖只有網址而沒有取得檔案時，要明確說明；來源平台腳本未實作時列為待適配，不可說已完全相容。不要上架任何作品。

### 不同 AI 網站：先匯出交接包

請使用這個平台的 MCP，唯讀匯出我有權讀取的作品：【填作品名稱或 ID】，供另一個 AI 搬到夜灣。
請保留角色設定、開場／範例、全部世界書（含停用項、原始 ID、條件與順序）、Regex、UI 規則，以及可取得的原始圖片。優先交付來源平台正式匯出格式，例如 JSON／PNG／CHARX；如工具沒有匯出功能，請把可讀取的原始資料存成檔案並附來源清單。不要只提供摘要。
附交接說明：實際取得哪些資料、世界書與圖片數、哪些圖片只有 URL、哪些項目因來源工具限制未取得。保留原作，不修改、刪除或發布來源作品。請交付能帶到另一個 AI 對話的檔案；若目前平台無法提供檔案，請清楚說明，不要編造附件或下載網址。

### 在夜灣接收交接包

這是另一個 AI 使用來源平台 MCP 匯出的原始作品與交接說明。請先核對附件是否齊全，再使用 YoruBay Creator MCP 遷移成夜灣作品包。保留原作題材、人物關係、玩法與文風；世界書、圖片、Regex 和 UI 都要清點，原文及停用條目不要省略。按需要適配夜灣原生狀態、場景圖、立繪與顯示介面，列出保留／改動／待適配項目。最後驗證並用 prepare_yorubay_package 交付可本機匯入的 .yorubay.zip。不要發佈作品；不能取得的內容不要假裝已轉換完成。

## 4. 檔案拿到後怎麼用
在夜灣的作品頁展開「本機角色與匯入」，使用「匯入作品（JSON／PNG／ZIP）」選擇檔案。有圖片與多本世界書時，優先匯入完整 .yorubay.zip，查看預覽與待適配項目後確認。匯入本機不等於公開上架；圖片隨作品保存在目前瀏覽器，換裝置前請備份。

JSON 適合角色設定；PNG 適合單封面角色卡；ZIP 適合包含分檔世界書、Regex 與多張圖片的完整作品。外平台專用腳本仍需逐項適配，不保證原樣執行。夜灣 MCP 不會自動下載外部圖片 URL，請提供可取得的原圖，或明確保留連結與缺漏報告。

## 5. 常見問題
- 看不到 prepare_yorubay_package：重新整理工具清單／重新連接，再開新對話確認。仍沒有時，請回報 AI 客戶端名稱與實際工具清單。
- 工具回傳資源卻沒有下載按鈕：附件的呈現由 AI 客戶端決定。請 AI 將工具回傳的實際資源另存檔案；若它無法處理 ZIP，改用支援檔案資源的客戶端，保留原檔。不要把摘要當成完整轉換，也不要相信憑空生成的網址。
- 大量世界書／圖片超過容量：要求分卷或分包並列出數量；不要用刪設定、裁條目或忽略圖片的方式假裝成功。Creator ZIP 工具上限 12 MiB；夜灣本機 ZIP 上限 32 MiB。原生已安裝世界書最多 6 包，單包最多 512 筆，仍受容量限制。
- 費用與資料：Creator 不代呼叫故事模型；創作所用 AI 由你選擇的平台提供。交給 AI 的原作資料會進入該平台的處理流程；本機匯入夜灣不會自動公開上架。
