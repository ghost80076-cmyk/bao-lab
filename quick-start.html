NEW PLAYER · 三步驟

不用懂程式，也能開始玩。

選一個想走進的作品，連上自己的 AI，就能開始故事。一般作品不需要先讀懂其他進階設定。

1

選一個想走進的故事

回首頁按「開始探索」，打開想玩的作品，再按「開始故事」。一般作品會直接進入「快速開始 · 只連接 AI」；需要選開局方式的特殊世界，則會先顯示完整設定。

去探索作品 →
2

選一種 AI 連線方式

進入快速開始後，先選「使用帳號 API 額度」或「使用自己的 API」。這是第一次玩真正需要做的主要設定；敘事、玩家身份（Persona）與記憶可以先沿用預設值。

使用帳號 API 額度

如果這個選項目前有開放，登入夜灣帳號後直接選模型即可，不需要貼自己的 API Key。實際可用模型與點數以帳號頁顯示為準。

登入／查看帳號與 API 點數 →

使用自己的 API Key

選擇 AI 服務商（Provider）和 AI 模型（Model），再貼上同一家服務商的連線金鑰（API Key）。不同服務商的金鑰不能混用。

還沒有 Key，可以到服務商官方頁面建立：

OpenRouter｜建立 API Key ↗
Google AI Studio｜建立 Gemini API Key ↗

我想用 LM Studio 本機模型

在「使用自己的 API」裡選「LM Studio（本地 AI）」。先在 LM Studio 載入模型並啟動 Local Server，再到 Server Settings 開啟 Enable CORS。回到夜灣後確認本機 API 網址（預設 http://127.0.0.1:1234/v1），再按「讀取本機模型」。本地模式預設不需要雲端 API Key。

查看 LM Studio 完整連線教學 →

「AI 模型」是什麼？

AI 模型（Model）就是實際回覆你故事的 AI。先選你目前帳號或服務商可使用的模型。免費模型也可能有次數、地區或速率限制；付費模型可能產生費用。

3

按「開始故事」

帳號額度選好模型、自己的 API 完成模型與 Key，或 LM Studio 成功讀到本機模型後，直接按「開始故事」。快速開始不需要先走完五個進階步驟；想調整敘事、Persona 或記憶時，再切到「完整設定」。

回夜灣開始玩 →
開始前記得兩件事

連線金鑰（API Key）不要放進角色卡、公開訊息或截圖。AI 模型使用量可能由服務商收費，免費不代表無限使用。

故事主要保存在這台裝置；聊天內容仍會送到你選擇的 AI 服務商。清除瀏覽器資料或換裝置前，請先備份故事。

卡住了怎麼辦？

金鑰無效：確認服務商選對、金鑰貼完整。
模型不能用：檢查模型名稱、服務商的地區限制與帳戶額度。
要自己設定連線網址：使用「展開進階連線欄位」或切到完整設定。
