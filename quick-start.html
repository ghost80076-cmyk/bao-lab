NEW PLAYER · 三步驟

不用懂程式，也能開始玩。

BAO/LAB 是自己選角色、自己連接 AI 的故事網站。第一次來？照著下面做就好，其他設定可以先用預設值。

1

先選一個想玩的角色

回到首頁，按「開始玩／探索作品」，點選喜歡的角色，進入「建立故事」。敘事、顯示和個人設定可以先保留預設值，按「下一步」即可。

去選角色 →
2

拿到自己的 AI 連線鑰匙

API Key 就像使用 AI 服務的鑰匙。到你選擇的服務商取得 Key，在建立故事的第 4 步「API」選對服務商、貼上 Key，再選擇相符的模型。

我還沒有 Key，從哪裡取得？

以下是兩種可以自行選擇的連線方式，依官方頁面操作即可：

  • OpenRouter｜建立 API Key ↗（一組 Key 可使用其支援的不同模型）
  • Google AI Studio｜建立 Gemini API Key ↗

取得 Key 後，回 BAO/LAB 選擇對應的服務商。不要把不同服務商的 Key 混用。

什麼是模型？我該選哪個？

模型就是實際回覆故事的 AI。先選你取得 Key 的服務商所支援、你有權使用的模型即可；免費資格、價格、額度和地區限制會變動，請以服務商當下資訊為準。

已經會用 API？可以直接略過上面的說明，使用你原本的 Key 與模型。

3

按「開始故事」，就能聊天了

第 5 步記憶設定先保留預設值，按「開始故事」，再輸入第一句話。之後想調整世界模組、記憶強度或其他選項，再打開進階功能即可。

回 BAO/LAB 開始玩 →
開始前記得兩件事

不要把 API Key 貼進角色卡、公開貼文或截圖。使用 AI 可能產生服務商費用；有免費方案也不代表無限免費。

故事主要存在這台裝置；對話請求仍會送往你選擇的 AI 服務商。清除瀏覽器資料或換裝置前，先備份故事。

卡住了怎麼辦？

Key 無效：確認選對服務商、Key 貼完整。
模型無法使用：確認模型名稱、帳戶額度及服務商地區限制。
不想研究設定：其他步驟先留預設，真的有需要再調整。
