NEW PLAYER · 三步驟

不用懂程式，也能開始玩。

選一個想玩的角色，連上自己的 AI，就能開始故事。一般角色不需要先讀懂其他設定。

1

選一個喜歡的角色

回首頁按「開始玩 · 選角色」，點擊作品，再按「開始故事」。一般角色會直接進入「快速開始 · 只設定 AI」。特殊世界如果需要選開局方式，則會先顯示完整設定。

去選角色 →
2

選 AI 服務，貼上你的鑰匙

API Key 就是使用 AI 服務的鑰匙。在 BAO/LAB 選擇服務商和模型，把對應的 Key 貼進欄位即可。有完整預設的模型不必自己填模型名稱與連線網址。

我沒有 Key，去哪裡拿？

可以選擇自己想用的服務商，依官方畫面建立 Key：

OpenRouter｜建立 API Key ↗
Google AI Studio｜建立 Gemini API Key ↗

取得後回到 BAO/LAB，選擇相同服務商；不同家的 Key 不能混用。

「模型」是什麼？

模型就是實際回覆你故事的 AI。先選服務商提供且你的帳戶可使用的模型。免費模型也可能有次數、地區或速率限制；付費模型可能產生費用。

3

按「開始故事」，直接聊天

輸入 Key 後按「開始故事」就好。敘事、個人設定與記憶會沿用預設值，不必再逐一按完五個步驟。想調整時，隨時可以切換成「完整設定 · 自訂故事」。

回 BAO/LAB 開始玩 →
開始前記得兩件事

API Key 不要放進角色卡、公開訊息或截圖。模型使用量可能由服務商收費，免費不代表無限使用。

故事主要保存在這台裝置；聊天內容仍會送到你選擇的 AI 服務商。清除瀏覽器資料或換裝置前，請先備份故事。

卡住了怎麼辦？

Key 無效：確認服務商選對、Key 貼完整。
模型不能用：檢查模型名稱、服務商的地區限制與帳戶額度。
要自己設定連線網址：使用「展開進階連線欄位」或切到完整設定。
