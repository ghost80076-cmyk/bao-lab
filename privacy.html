隱私權政策

最後更新：2026 年 10 月 3 日

服務條款隱私權政策年齡與內容政策燈火與退款創作者政策
夜灣以 Local-first 為核心。
私人故事、角色、記憶與世界狀態原則上保存在你自己的裝置；只有你主動使用雲端同步、夜灣燈火、作者發布或其他線上功能時，才會為完成該功能處理必要資料。

1. 本機故事與設定

你建立或匯入的故事、對話、角色、記憶、世界狀態、分支、閱讀與內容偏好等資料，主要儲存在你所使用的瀏覽器，例如 IndexedDB 或本機儲存空間。不同裝置、瀏覽器或瀏覽器設定檔的本機資料可能彼此獨立。

夜灣不要求你先把私人故事上傳到夜灣帳號，才能使用自己的 API 進行故事。清除網站資料、無痕模式、瀏覽器重設或裝置損壞，都可能使本機資料遺失，因此重要故事請自行保留匯出備份。

2. 自備 API Key（BYOK）

你自行提供的 AI API Key 不會存入夜灣帳號資料，也不會被寫進故事匯出檔或 Google Drive 故事同步檔。瀏覽器為完成你選擇的 AI 連線，仍需要在請求期間使用該金鑰。

當你使用自己的 AI 服務時，提示詞、故事脈絡與你提交的內容會傳送到你選擇的 AI 服務商或自訂端點。該服務商如何保存、記錄或使用請求，依其自身政策與你的帳號設定而定。

3. 夜灣帳號資料

只有在你主動註冊或登入夜灣帳號時，夜灣才會處理帳號功能所需資料，例如帳號名稱、顯示名稱、公開玩家編號、密碼驗證資料、恢復碼驗證資料、登入 Session、帳號狀態與燈火餘額。

密碼與恢復碼不以可直接還原的明文作為帳號驗證資料保存。恢復碼在建立或重設時應由你自行妥善保存；夜灣無法替你公開保管私人恢復碼。

4. 使用夜灣燈火時的資料

當你使用夜灣提供的模型服務時，為了把請求送到第三方 AI 服務並完成計價，故事請求中的必要訊息會經過夜灣的後端或 Relay，再傳送至所選模型服務商。

夜灣會保存完成帳務與風控所需的使用紀錄，例如請求識別碼、玩家／帳號識別、模型服務商、模型、請求類型、狀態、用量與成本／結算資訊。這些帳務紀錄的目的不是建立可供夜灣閱讀的私人聊天紀錄庫。

第三方 AI 服務商、雲端基礎設施或 Relay 供應商仍可能依自己的安全、濫用防護與服務政策處理連線紀錄或請求內容。

5. Google Drive 故事同步

只有你主動連結 Google Drive 並執行同步時，夜灣才會使用 Google OAuth 存取應用程式專用資料空間。授權範圍為 https://www.googleapis.com/auth/drive.appdata，用來在你自己的 Google Drive appDataFolder 建立、讀取與更新夜灣故事備份。

此權限不能讓夜灣任意瀏覽你的一般 Google Drive 檔案。OAuth 存取權杖不會被寫進故事備份。中斷 Google 連結或刪除本機故事，不等於自動刪除已存在於 Google Drive 應用程式資料空間的備份。

6. 作者身份與公開資料

如果你建立作者身份並提交公開作者資料，作者名稱、作者 ID、作者簡介、作品資訊，以及你主動提供的外部支持連結可能成為公開資料。請只填寫你願意公開的資訊。

作者發布流程可能利用 GitHub 儲存公開作品與作者目錄，並建立審核用的變更紀錄。這不會把你的私人故事自動變成公開作品。

7. 成人內容偏好與年齡確認

成人內容預設隱藏。當你主動開啟成人內容時，目前的「已滿 18 歲」確認是保存在裝置上的內容偏好，不是政府證件驗證，也不要求你為此上傳身分證件。

更多規則請見「年齡與內容政策」。

8. 技術資料、第三方服務與跨境處理

造訪網站或使用線上功能時，網站託管、CDN／網路、防濫用、AI 模型、Google Drive、GitHub 或其他必要服務供應商可能依其服務性質處理 IP 位址、瀏覽器資訊、請求時間、錯誤或安全紀錄。

部分服務供應商的伺服器位於台灣以外，因此你使用相關功能時，資料可能跨境傳輸。夜灣會盡量限制傳送內容在完成該功能所必要的範圍內，但第三方服務仍依其自身政策負責其資料處理。

9. 保留、刪除與安全

本機資料由你的瀏覽器保存，直到你刪除、清除網站資料或瀏覽器自行移除。帳號、Session、使用量與交易相關資料會依維持帳號、帳務、安全、爭議處理與法令需求所必要的期間保存；失效 Session 可被登出、撤銷或到期。

夜灣會採取合理的技術措施保護線上服務，但任何網站、瀏覽器儲存或第三方雲端都無法保證絕對安全。請不要把 API Key、密碼、恢復碼、金融資料或其他高度敏感資訊寫進公開作者頁或公開 Issue。

10. 查詢、更正與聯繫

如果你需要查詢帳號資料、更正公開作者資訊、處理帳號刪除或提出隱私問題，請使用夜灣網站目前提供的支援管道或 GitHub 專案問題回報 聯繫。

若問題包含私人故事、帳號憑證、付款資訊或其他敏感資料，請不要直接貼在公開 Issue；先以最少必要資訊說明問題，再依支援指示處理。

11. 政策變更

當夜灣新增帳號、付款、同步、模型路由或其他資料處理方式時，本政策可能更新。更新會反映在頁面上的「最後更新」日期；依法需要額外通知或同意時，會依適用規定辦理。
