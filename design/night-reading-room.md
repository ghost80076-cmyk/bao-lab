# BAO/LAB 視覺提案｜夜讀書房（第一版）

不是仿照其他網站的配色，而是保留 BAO/LAB 原有的近黑、薰衣草紫和薄荷綠，把「角色是封面、故事是藏書、聊天是閱讀」做成一致的視覺語言。

## 核心規則

- **畫面主角：** 首頁的角色與故事、探索頁的立繪、人物頁的單張肖像、書庫的故事封面。工具與後設資訊往次層退。
- **用色：** 近黑 `#090b10`；主文字暖白 `#f1eee8`；弱化文字灰藍 `#a7aebc`；主要操作沿用品牌紫 `#9c8cff`；薄荷綠僅用於提示／導覽。吉祥物形象不改色，角色卡原始照片不重新裁切存檔。
- **版面：** 主標題明顯，正文舒展；卡片一致使用低對比細邊框、適度圓角、少量陰影。角色封面使用 3:4 顯示裁切（只影響 CSS，不改原圖）。手機採兩欄角色畫廊，小尺寸不擠進更多文字。
- **操作：** 「開始故事／繼續此故事」保持唯一視覺主 CTA；手動存檔、改名、刪除與 API 操作原節點、事件與資料流程全部保留，僅調整外觀。
- **隔離：** 只更動首頁、作品探索、人物詳情、書庫的網站外層；不更動角色作者提供的 HTML、故事回覆、聊天捲動、記憶、API Key 或 IndexedDB。

## 第一輪具體落地

`css/bao-editorial.css` 是獨立的展示層，經 `js/bao-visual-ui.js` 載入在現有品牌主題之後；若要撤回，移除載入行即可，沒有資料遷移。桌面與手機的首頁、角色畫廊、人物詳情和故事書庫截圖由專用 E2E 工作流程產生，提供實際畫面驗收。

這是視覺方向的**第一輪供確認稿**，不是宣稱已完成全站統一。下一輪需以實際截圖和手機實測再調整字重、素材比例、關係／狀態人物面板，以及故事書庫的資訊密度；任何功能性整併必須另開修改並獨立驗收。
