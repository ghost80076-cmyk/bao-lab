連接 MCP跨平台搬運複製指令匯入夜灣

1. 連接與下載

在支援遠端 MCP 的 AI 客戶端，找到新增 MCP 伺服器／連接器入口，名稱填 YoruBay Creator，貼上以下 Server URL，驗證選不需要（No authentication），再於對話啟用工具。

https://yorubay-creator-mcp.ghost80076.workers.dev/mcp

連線方式：Streamable HTTP。各 AI 平台的入口、方案與權限不同，以其實際功能為準；不支援遠端 MCP 的網站無法只靠貼指令取得工具能力。

ChatGPT 網頁／Work：逐步連接
  1. 開啟 ChatGPT 外掛程式，按「＋」，選 Add custom MCP server。
  2. 名稱填 YoruBay Creator，貼上本頁的 MCP 網址，驗證選 No authentication。
  3. 確認後建立並安裝；開新對話，輸入 @ 選擇 YoruBay Creator，再貼下方指令。

是否能新增自訂 MCP 仍受帳號與工作區政策影響。若沒有這個入口，請以目前平台支援的方式連接。

2. 用別的平台 MCP，再交給夜灣

① 讀取來源AI 使用來源平台 MCP，取得你有權讀取的角色、世界書、Regex 與圖片清單。
② 整理與適配同一個 AI 核對原始資料，再使用夜灣 MCP 整理設定、狀態與介面。
③ 交付作品包下載經驗證的 .yorubay.zip，再到夜灣本機匯入。

兩個 MCP 在同一個 AI 客戶端：同時啟用兩邊工具，使用下方的雙 MCP 指令。

分屬不同 AI 網站：先用來源 MCP 匯出檔案，下載後交給能連接夜灣 MCP 的 AI。使用「先匯出交接包」與「接收交接包」兩段指令。

由 AI 客戶端負責依序使用工具。來源 MCP 不會自行呼叫夜灣 MCP；不同網站的對話也不會自動互通。工具讀不到的內容需要補原始檔，不能用摘要假裝完整搬運。

4. 拿到檔案後，匯入夜灣

  1. 到作品頁展開「本機角色與匯入」。
  2. 使用「匯入作品（JSON／PNG／ZIP）」選擇檔案。
  3. 完整作品優先選 .yorubay.zip；檢查預覽與待適配項目後確認。

JSON 適合設定；PNG 適合單封面角色卡；ZIP 一次帶入多本世界書、Regex 與圖片。匯入本機不等於公開上架；換裝置前請先備份。

遇到問題

看不到完整作品包工具？

重新整理工具清單／重新連接，再開新對話，用「確認連線」指令檢查。完整作品包工具名稱是 prepare_yorubay_package。仍沒有時，請回報 AI 客戶端名稱與實際工具清單。

沒有下載按鈕，或圖片／腳本沒有完整搬過來？

檔案資源如何呈現由 AI 客戶端決定，請要求它將實際工具資源另存檔案；若不能處理 ZIP，改用支援檔案資源的客戶端並保留原檔，不要接受編造的下載網址。

夜灣 MCP 不會自動下載外部圖片 URL；請提供原圖，或列明只有連結。外平台專用腳本需要逐項適配，不能保證原樣執行。要求 AI 列出保留、適配、缺漏清單。

世界書或圖片太多？

要求分卷／分包並核對數量，不要刪設定或忽略圖片。Creator ZIP 工具上限 12 MiB；夜灣本機 ZIP 上限 32 MiB。原生已安裝世界書最多 6 包、單包最多 512 筆，仍受容量限制。

Creator 不代呼叫故事模型；創作由你選擇的 AI 平台處理。交給 AI 的作品資料會進入該平台的處理流程。夜灣本機匯入不會自動公開作品。
