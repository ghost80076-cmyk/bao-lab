燈火與退款政策

「燈火」是夜灣提供的 AI 模型使用額度。
自己的 API，自己掌燈；沒有 API，也可以選擇使用夜灣提供的一盞燈。

1. 燈火是什麼

夜灣 YoruBay 為 AI 互動故事與角色扮演工具。使用者可自行提供並使用支援的第三方 AI 服務 API Key（BYOK）；夜灣另提供可選購的 AI 模型使用額度「燈火」，供使用者於未自行提供 API Key，或選擇使用夜灣提供之模型服務時使用。

燈火用於支付使用者透過夜灣產生的 AI 模型運算及相關服務成本，僅限夜灣指定的 AI 服務使用。

燈火不可在使用者間轉讓、交易或兌換現金，也不提供提領、投資或玩家間支付功能；就本站功能設計而言，燈火是站內 AI 服務使用額度，不是夜灣提供的虛擬貨幣、電子支付工具、投資商品或可自由流通的數位資產。

2. 購買與入帳

可購買的燈火方案、價格、幣別、付款方式與實際取得額度，以付款或帳號頁面在交易當下顯示的內容為準。若目前流程需要提供玩家編號並由管理員確認，燈火會在付款資料核對完成後加入對應帳號。

請在付款前確認玩家編號、方案與金額。不得以他人付款資料、盜刷、偽造付款證明或其他不正當方式取得燈火。

3. 如何扣除燈火

使用自己的 API Key 不會消耗夜灣燈火。使用夜灣提供的模型服務時，消耗量可能依模型、提供商、輸入與輸出 token、提示快取、長上下文費率、路由與其他實際模型成本而不同。

夜灣可能在送出請求時先預留足以完成該次請求的額度，並在取得實際使用量後進行結算。模型或費率調整時，夜灣會以當下介面所顯示的費率或計價資訊為準。

4. 失敗、中斷與重複扣款

如果夜灣能確認請求未成功且沒有形成可計費的模型使用，系統會取消預留或返還相應燈火。若第三方服務已產生實際用量或成本，即使回覆之後因網路中斷而未完整顯示，仍可能依實際成本結算。

若發生明顯重複扣款、帳務錯誤或請求失敗卻未正確返還，請保留發生時間、玩家編號與必要的請求資訊後聯繫支援；不要提供 API Key、密碼或私人故事全文。

5. 退款與法定解除權

夜灣不以本政策預先排除消費者依法享有的退款、解除契約或其他強制權利。是否可退款，以及退款範圍，會依付款狀態、燈火是否已使用、第三方模型成本是否已發生、付款服務商規則與適用法律個別處理。

台灣通訊交易原則上可能有法定解除權；非以有形媒介提供的數位內容或一經提供即完成的線上服務，只有在符合法律所定條件、事前清楚告知並取得消費者同意時，才可能適用解除權例外。夜灣不會只靠本政策的一句「不退款」取代依法需要的事前告知或同意程序。

燈火不可「提領」或作為現金兌換工具；這與依法申請交易退款是兩件不同的事。合法退款成立時，會依實際付款方式與可退款金額處理。

6. 餘額與終止

夜灣不會以未事先揭露的條件任意使已購燈火失效。若未來某一方案有特定有效期限或其他重要限制，會在購買前明確標示。

帳號因違規被限制時，夜灣仍會依適用法律、付款狀態與實際已使用服務處理剩餘燈火與退款問題；停權本身不會自動消滅依法不得排除的權利。

7. 費率變更

第三方 AI 模型價格可能調整。夜灣可更新未來請求的燈火計價方式，但不會追溯改寫已完成請求的既有結算。重大計價方式變更會以介面、政策頁或其他合理方式說明。
