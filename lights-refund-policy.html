1. 燈火是什麼

夜灣 YoruBay 為 AI 互動故事與角色扮演工具。使用者可自行提供並使用支援的第三方 AI 服務 API Key（BYOK）；夜灣另提供可選購的 AI 模型使用額度「燈火」，供使用者於未自行提供 API Key，或選擇使用夜灣提供之模型服務時使用。

燈火主要用於支付使用者透過夜灣產生的 AI 模型運算及相關服務成本，僅限夜灣指定的 AI 服務使用。夜灣提供燈火的目的，是讓沒有自備 API 或希望使用夜灣代為連線的玩家可以使用模型服務；燈火並不是以模型用量差價作為主要收益來源的儲值商品。

燈火不可在使用者間轉讓、交易或兌換現金，也不提供提領、投資或玩家間支付功能；就本站功能設計而言，燈火是站內 AI 服務使用額度，不是夜灣提供的虛擬貨幣、電子支付工具、投資商品或可自由流通的數位資產。

2. 購買與入帳

台灣燈火目前採新台幣方案：NT$250 → 5,000 燈火、NT$500 → 10,000 燈火、NT$1,000 → 20,000 燈火、NT$2,500 → 50,000 燈火。正式交易時仍以付款頁當下顯示的方案、金額與交易結果為準。

燈火屬數位服務使用額度。付款完成並確認交易後，額度會加入對應的夜灣帳號；正式金流自動入帳功能上線前，如需購買請先透過官方聯絡管道確認玩家編號與付款方式。

Ko-fi 用於海外玩家支持夜灣，支持款不會自動轉換為燈火。海外玩家若需要購買燈火，請先聯絡班長確認可用方式。

請在付款前確認玩家編號、方案與金額。不得以他人付款資料、盜刷、偽造付款證明或其他不正當方式取得燈火。公開方案與購買說明可查看 夜灣燈火方案。

3. 如何扣除燈火

使用自己的 API Key 不會消耗夜灣燈火。使用夜灣提供的模型服務時，消耗量可能依模型、提供商、輸入與輸出 token、提示快取、長上下文費率、路由與其他實際模型成本而不同。

夜灣可能在送出請求時先預留足以完成該次請求的額度，並在取得實際使用量後進行結算。模型或費率調整時，夜灣會以當下介面所顯示的費率或計價資訊為準。

4. 失敗、中斷與重複扣款

夜灣以「第三方是否實際產生成本」作為失敗請求結算的主要原則。如果請求在第三方 AI 服務產生可計費用量前失敗，夜灣會取消預留或返還相應燈火。

如果第三方 AI 服務已接受請求並產生實際模型用量或費用，該部分仍會依實際成本結算。這包含回覆之後因網路中斷、瀏覽器關閉、Relay 或傳輸異常而未完整顯示的情況；夜灣不承諾替使用者吸收第三方已實際發生的模型成本。

模型拒答、安全攔截、內容為空或其他由第三方模型完成並計費的回應，也不當然視為「未發生成本的失敗請求」。若第三方未計費，則不應扣除該次對應燈火；若已產生實際用量，則按實際用量結算。

若發生重複扣款、計價錯誤、預留額度未正確釋放，或其他可確認的帳務異常，夜灣會返還錯誤扣除的燈火。夜灣得視個別事故提供額外燈火作為服務補償，但此類補償不代表第三方已發生成本必須一律由夜灣吸收。

5. 退款與法定解除權

夜灣不以本政策預先排除消費者依法享有的退款、解除契約或其他強制權利。是否可退款，以及退款範圍，會依付款狀態、燈火是否已使用、第三方模型成本是否已實際發生、付款服務商規則與適用法律個別處理。已經轉化為第三方模型實際用量或成本的部分，與尚未使用的燈火餘額會分開判斷。

台灣通訊交易原則上可能有法定解除權；非以有形媒介提供的數位內容或一經提供即完成的線上服務，只有在符合法律所定條件、事前清楚告知並取得消費者同意時，才可能適用解除權例外。夜灣不會只靠本政策的一句「不退款」取代依法需要的事前告知或同意程序。

燈火不可「提領」或作為現金兌換工具；這與依法申請交易退款是兩件不同的事。合法退款成立時，會依實際付款方式與可退款金額處理。

6. 餘額與終止

夜灣不會以未事先揭露的條件任意使已購燈火失效。若未來某一方案有特定有效期限或其他重要限制，會在購買前明確標示。

帳號因違規被限制時，夜灣仍會依適用法律、付款狀態與實際已使用服務處理剩餘燈火與退款問題；停權本身不會自動消滅依法不得排除的權利。

7. 費率變更

第三方 AI 模型價格可能調整。夜灣可更新未來請求的燈火計價方式，但不會追溯改寫已完成請求的既有結算。重大計價方式變更會以介面、政策頁或其他合理方式說明。
