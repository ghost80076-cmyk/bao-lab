這頁是完整連線參考。如果只是第一次想開始玩，先看「三步開始」會比較快。

選一條 AI 連線路線。

夜灣可以使用夜灣燈火、自備連線金鑰（BYOK），也可以連接同一台電腦上的 LM Studio 本地 AI。不同路線的費用、資料流向與設定方式不同，請只看你正在使用的那一段。

連線金鑰（API Key）使用 AI 服務的私人鑰匙；不要公開。
AI 服務商（Provider）提供模型與計費的服務，例如 OpenRouter 或 Google。
AI 模型（Model）實際產生故事回覆的 AI。
模型代號（Model ID）服務商辨識某個模型的名稱；一般預設服務會自動帶入。
可以先看介面，不一定要先花錢。免 API 的示範模式只用來體驗操作；真正請 AI 寫新劇情時，可以使用自己的雲端連線金鑰，也可以使用 LM Studio 本地模型。免費模型或免費額度有用量、速率及地區限制，並非無限免費。

路線 A：夜灣燈火

適合已取得夜灣帳號與燈火、想直接選模型開始的玩家。這條路線不需要貼自己的 API Key；實際可用模型與燈火以帳號頁顯示為準。

  1. 登入夜灣帳號。
  2. 回到作品的「連接 AI」，選「使用夜灣燈火」。
  3. 選擇目前可用模型後開始故事。

路線 B：OpenRouter

適合想用一組連線金鑰，嘗試多個 AI 模型的玩家。模型、價格與可用性會變動，請以官方頁面為準。

  1. 開啟 OpenRouter 並註冊或登入。
  2. 進入 API Keys，建立一組新的連線金鑰。
  3. 複製金鑰，回到夜灣 的「連接 AI」。
  4. 選擇 OpenRouter，確認 AI 模型，貼上金鑰後開始故事。

路線 C：Google Gemini

適合想直接使用 Gemini 的玩家。免費層、可用模型與額度依官方規則及所在地區而定。

  1. 開啟 Google AI Studio，登入 Google 帳號。
  2. 在 API Keys 依畫面指示建立連線金鑰；如需建立專案或設定計費，先閱讀官方說明。
  3. 回到夜灣 的「連接 AI」，選擇 Gemini 與想使用的模型。
  4. 貼上金鑰，確認設定後開始故事。

路線 D：LM Studio 本地 AI

適合想讓模型在自己的電腦上運行、不走雲端 API 的玩家。預設不需要雲端 API Key。

  1. 在 LM Studio 下載並載入模型。
  2. 如果畫面中央開著 Settings 設定視窗，先按右上角 × 關閉；不要在 Settings → Developer 裡找 API Server。
  3. 回到 LM Studio 主畫面，點左側主導覽的 Developer 頁面，切換 Start Server。
  4. 到 Server Settings 開啟 Enable CORS。
  5. 回 夜灣 YoruBay 選擇「LM Studio（本地 AI）」，確認卡片上的本機 API 網址（預設 http://127.0.0.1:1234/v1），再按「讀取本機模型」。

回到夜灣，怎麼設定？

  1. 回到首頁，選作品並按「開始故事」。
  2. 一般作品會進入快速開始，只要處理「連接 AI」；特殊世界或想自訂敘事時再用完整設定。
  3. 夜灣燈火：選「使用夜灣燈火」與可用模型。
  4. 自己的 API：選服務商（Provider）與模型（Model），貼上相符的 API Key。
  5. LM Studio：在「使用自己的 API」裡選本地 AI，啟動 Server 後讀取本機模型。
  6. 只有自訂連線才需要手動調模型代號（Model ID）或連線網址（Base URL）。

安全、隱私與費用

  • 連線金鑰不要貼到角色卡、公開貼文、截圖、客服訊息或 GitHub。
  • 如懷疑金鑰外洩，立刻到服務商後台撤銷並重新建立。
  • 故事優先保存在你的裝置；發送對話時，必要的故事脈絡仍會傳送到你選擇的 AI 服務商。
  • 可先使用免費方案或設定服務商的預算／額度限制。提示快取（Prompt Cache）可能降低部分費用，但不保證命中。
  • 清除瀏覽器資料、使用無痕模式或更換裝置，可能使本機故事消失；請定期備份。
遇到錯誤怎麼辦？

401／金鑰無效：檢查 AI 服務商是否選對、金鑰是否貼完整，必要時重新建立。
429／額度不足：檢查免費額度、速率限制與帳戶餘額，稍後再試或換模型。
找不到模型：核對模型代號（Model ID）與所選服務商。
網路或瀏覽器錯誤：檢查服務商是否允許瀏覽器直連與目前瀏覽器相容性。
