第一次使用自己的 AI 模型？從這裡開始。

申請 API Key，開始你的第一段故事。

BAO/LAB 採用 BYOK（Bring Your Own Key）：由你向模型服務商取得 API Key，再貼到 BAO/LAB 的 API 設定。BAO/LAB 不代售模型額度；使用量與費用依你選擇的服務商而定。

先不用花錢也能看看介面。若網站提供免 API 的示範模式，可先體驗操作；真正向模型發送新對話時，通常需要自己的 Key。免費模型或免費額度有速率、用量及地區限制，並非無限免費。

路線 A：OpenRouter

適合希望用一組 Key 嘗試不同模型的玩家。部分模型提供免費路線，但模型名稱、限制及可用性會變動。

  1. 開啟 OpenRouter 官方網站並註冊或登入。
  2. 進入 API Keys 頁面，建立一組新的 Key。
  3. 複製 Key，回到 BAO/LAB，選擇 OpenRouter 對應的供應方式與模型。
  4. 把 Key 貼入 API Key 欄位，確認 Model ID 與供應商一致，再開始故事。
前往 OpenRouter API Keys ↗查看模型與價格 ↗

不要只依模型名稱判斷是否免費；以當下官方模型頁的價格與限制為準。

路線 B：Google Gemini API

適合想直接使用 Gemini 的玩家。是否提供免費層、可用模型與額度依官方當前規則及所在地區而定。

  1. 開啟 Google AI Studio，登入 Google 帳號。
  2. 在 API Keys 頁面依畫面指示建立 Key；如需建立專案或設定計費，先閱讀官方說明。
  3. 回到 BAO/LAB，選擇 Gemini 供應方式及支援的模型。
  4. 貼入 Key，確認模型設定後開始故事。
前往 Google AI Studio ↗查看官方價格與免費層 ↗

回到 BAO/LAB，開始設定

  1. 回到首頁，進入探索角色並選擇一個故事。
  2. 設定敘事、顯示與玩家 Persona，前往第 4 步「API」。
  3. 選擇與 Key 相符的供應商，填入 Key，核對 Model ID；不要把 OpenRouter Key 貼到 Gemini 供應方式。
  4. 依畫面完成記憶設定並開始故事。若尚未提供正式示範故事，可先查看網站現有的角色或 Demo。

安全、隱私與費用：開始前必讀

  • API Key 就像使用額度的憑證：不要貼到公開貼文、角色卡、截圖、客服訊息或 GitHub。
  • 只在你信任的網站輸入 Key；如懷疑外洩，立即到供應商後台撤銷並重新建立。
  • 故事資料優先保存在本機，不代表模型請求完全離線。發送對話時，必要內容仍會傳送至你選擇的模型供應商，請閱讀其資料政策。
  • 可先使用免費方案或設定供應商的預算／額度限制。快取可能降低部分成本，但不保證命中或固定省下多少費用。
  • 清除瀏覽器資料、使用無痕模式或更換裝置，可能使本機故事消失；請定期使用網站的備份功能。
遇到錯誤怎麼辦？

401／無效 Key：檢查供應商是否選對、Key 是否完整，必要時重新建立。
429／額度不足：檢查免費額度、速率限制與帳戶餘額，稍後再試或更換可用模型。
模型找不到：核對官方 Model ID 與所選供應商。
網路或瀏覽器錯誤：檢查服務商是否允許瀏覽器直連及目前瀏覽器相容性。
