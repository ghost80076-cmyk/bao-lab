夜灣 YoruBay 是 AI 互動故事與角色扮演工具。
你可以使用自己的 API Key，也可以選擇使用夜灣提供的「燈火」連線。建立帳號、使用網站或使用夜灣線上服務，即表示你同意本條款中與該功能相關的規定。

1. 服務內容

夜灣提供角色與世界作品瀏覽、故事建立與保存、記憶與世界狀態工具、AI 模型連線、作品與作者頁面，以及其他與互動故事相關的功能。

夜灣採 Local-first 設計。自己的模型連線、本地故事、角色、記憶與世界狀態，原則上不以建立夜灣帳號為必要條件；使用夜灣燈火、作者身份或其他線上帳號功能時，可能需要登入。

2. 自備 API 與第三方 AI

你可以自行提供支援的第三方 AI 服務 API Key（BYOK）或自訂連線端點。你有責任確認自己有權使用該金鑰與服務，並遵守該服務商的條款、年齡限制、內容政策與費率。

AI 回覆由你所選擇的模型或服務商產生。模型可能出現錯誤、偏誤、虛構、不連續或不符合預期的內容；AI 輸出不代表夜灣的立場，也不應取代醫療、法律、財務或其他專業意見。

3. 夜灣帳號

你應提供可正常使用的帳號資料並妥善保管密碼、恢復碼與登入裝置。若發現未授權登入、憑證外洩或異常使用，請儘速登出、重設相關憑證並透過夜灣目前提供的支援管道聯繫。

不得出售、轉讓或以營利方式出租夜灣帳號或帳號存取權。公開作者身份與作品發布另依「創作者政策」處理。

4. 燈火

夜灣另提供可選購的 AI 模型使用額度「燈火」，供使用者於未自行提供 API Key，或選擇使用夜灣提供之模型服務時使用。燈火主要用於支付 AI 模型運算及相關服務成本；其購買、扣除、失敗請求結算、返還與退款依「燈火與退款政策」辦理。

燈火不提供玩家間轉讓、交易、提領或投資功能，不應被當作現金、付款工具或可自由流通的資產使用。

5. 年齡與成人內容

夜灣的一般內容並非以成人內容為預設。成人向作品與成人 MOD 預設隱藏，僅在使用者主動開啟並自我確認已滿 18 歲後顯示；若所在地法律或第三方 AI 服務要求更高年齡，仍須遵守較高要求。

涉及未成年人的性或剝削內容不因任何成人內容設定而被允許。完整規則請見「年齡與內容政策」。

6. 合理使用與禁止事項

你不得利用夜灣從事違法、詐欺、侵害他人權利、騷擾威脅、散布惡意程式、竊取憑證、規避安全或計費機制、破壞服務可用性，或大量自動化存取而妨害其他使用者的行為。

夜灣的公開程式碼、網站素材、品牌與第三方元件各自受其著作權、授權條款或其他權利規範。公開存取程式碼不代表取得超出適用授權或法律範圍的使用權。

7. 使用者與創作者內容

你對自己建立的原創角色、人設、故事設定與其他內容保留原有權利。當你選擇將作品發布至夜灣公開目錄時，你授予夜灣為提供、展示、索引、散布與維護該作品所必要的非專屬授權；詳細範圍依「創作者政策」辦理。

你應確認自己有權發布所上傳或提交的文字、圖片、程式片段、角色設定與其他素材。

8. 服務變更、暫停與終止

夜灣可能因維護、安全、第三方服務異常、法令要求或產品調整而變更、暫停或停止部分功能。我們會在合理可行的情況下提供說明，但不保證任何第三方模型、免費額度、外部 API 或網路路徑永久可用。

若帳號涉及明顯違法、濫用、安全風險、付款爭議或重大違反本條款，夜灣得限制相關線上服務或帳號存取。涉及已購燈火與依法應處理的退款，不因停權而排除消費者依法享有的權利。

9. 責任與服務現況

在適用法律允許的最大範圍內，夜灣以目前可提供的狀態提供服務，不保證第三方 AI 的正確性、不中斷、特定模型永久存在，或任何作品一定符合個人期待。

本條款不排除或限制依法不得排除的消費者權利、故意或重大過失責任，或其他強制法律責任。

夜灣可能因功能、付款方式、第三方服務或法律要求更新本條款；更新會以本頁「最後更新」日期反映。重大變更若依法需要另行通知或同意，我們會依適用規定處理。

如有條款、帳號、安全或侵權問題，請使用夜灣網站目前提供的支援管道或 GitHub 專案問題回報；請勿在公開頁面張貼密碼、API Key、恢復碼或私人故事內容。
